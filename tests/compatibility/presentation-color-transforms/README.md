# DrawingML 颜色变换样例

`make-fixtures.py` 从本仓库自制基础演示包生成一张 20 个色块的幻灯片。没有复制参考软件的实现或素材。样例和顺序见 `manifest.json`，重新生成应保持 SHA-256 不变。

每个色块为无边框实心矩形，中心不含文字，用于区分 sRGB、线性 RGB 与 HSL 运算，以及连续变换的执行顺序。`native-observations.json` 是官方 Linux 桌面 10.0.0-169 实际截图的中心像素记录；每个中心周围 7×7 像素均一致。截图哈希、画布范围和采样坐标一并记录。

实测需区分标准预期与参考实现：

- `tint` 的 0/25/50/100%、`shade`、两种变换顺序与标准数学预期相符。
- 彩色 HSL 计算个别通道可能有 1 级取整差异。
- 线性 scRGB 的 50% 按标准取整为 `BCBCBC`，参考桌面显示 `BBBBBB`。
- `%` 词法是兼容性探针：参考桌面读取 `50%` 的结果不等同于数值 `50000`；产品按标准百分比处理，不复制这一结果。
- 系统颜色在参考桌面跟随操作系统；产品读取文件中 `lastClr` 缓存，跨系统不保证一致。
- 连续 alpha 变换在参考桌面的结果与数学合成不同。本轮不扩大普通形状的透明度支持范围。

本样例不是完整 Strict OOXML 文件，也不证明支持 Strict 命名空间。透明度、渐变、主题样式与所有颜色修饰符的完整一致性不在结论内。
