# 独立透明度样例

`make-fixtures.py` 确定性生成自制的一页、12 个对象的 PPTX。对象坐标、修饰符和源文件 SHA-256 见 `manifest.json`。没有复制参考软件素材或实现。

目标是验证填充与边框透明度不应传播到正文：半透明红色填充、蓝色边框和不透明黑色 H 必须分别绘制；包括完全透明、椭圆、斜线与主题色。alpha 链使用 80% × 50% + 10% = 50%，原 XML 的顺序必须保留。

`native-observations.json` 来自官方 Linux 桌面 10.0.0-169 的实际打开截图，含哈希和采样像素。填充采样避开文字，边框采样选在 2mm 描边的外侧部分，避免边框叠到填充后改变颜色。字形中心的黑色证明文字保持不透明。

两个边界必须单独说明：参考程序的连续 alpha 修饰符显示接近首个 alpha（80%），产品遵循标准有序链（50%）；最后一行第一个对象为文字本身 50% 透明的控制组，目前普通文字独立透明度尚未支持，不计为显示一致。新支持范围限于普通图形填充与描边，不能推论完整文字、背景、图像效果及组效果兼容。
