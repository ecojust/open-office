# 演示模板

打开演示文稿后，点击顶部“模板”打开模板栏。内置模板随应用打包，可离线使用；自己保存的模板列在“我的模板”中。

## 内置设计

每套包含封面、内容和结尾三页，文字和几何形状均可编辑。10 套模板分别为：

| 模板 | 设计与用途 |
| --- | --- |
| 蓝图商务 | 蓝白分栏和建筑几何，适合项目汇报 |
| 深空科技 | 深色轨道和薄荷亮色，适合技术分享 |
| 暖白学术 | 纸感暖白和书卷风标题，适合课程与研究 |
| 森林随想 | 森林绿和植物几何，适合自然与生活 |
| 珊瑚创意 | 珊瑚橘和大胆拼贴，适合提案与作品展示 |
| 紫霞愿景 | 柔和渐变和圆形构成，适合品牌与愿景 |
| 黑白编辑部 | 黑白对比和报刊分栏，适合观点与故事 |
| 暖调复古 | 陶土暖色和双线边框，适合文化与经历 |
| 活力发布 | 荧光黄和阶梯版式，适合产品发布 |
| 清透留白 | 清透蓝绿和充足留白，适合简洁汇报 |

## 保存与切换

- **将当前演示存为模板**：输入名称，保存整份演示文稿的幻灯片、内容、主题和页面尺寸。不会将当前文件标记为已保存；同名模板分别保留。
- **使用模板**：点击预览后弹窗确认，替换当前演示的全部幻灯片和内容；保留当前文件名及保存位置，产生未保存修改。一次撤销即可恢复切换前的文稿。
- **自动保存**：若桌面版已开启自动保存且当前文稿有本机保存位置，确认切换后的内容会按自动保存设置写回当前文件；确认框会明确提示。
- **删除模板**：仅可删除自定义模板，需弹窗确认；不影响已经打开的演示文稿。

模板名称最多 60 个字符，单个模板最多 40 MB。自定义模板保存在当前应用或浏览器的本地存储中；清除应用数据或浏览器站点数据会一并清除，请将重要模板另存为 PPTX 留作备份。桌面版和不同浏览器的模板库相互独立。

## 开发验证

原创内置素材位于 `public/presentation-templates/`。`python scripts/generate-presentation-templates.py` 使用相同绘图指令生成 PPTX 与 SVG 封面，开发环境需要 `python-pptx` 和 `fontTools`。这些依赖不进入应用运行环境。

`npm run test:browser:ppt-templates` 验证真实界面确认、切换、撤销、保存模板及全部 10 套模板的 Rust 导入/导出与重开；`npm run test:browser:ppt-templates-storage` 验证真实 IndexedDB 持久化和事务失败回滚。浏览器验证不能代替原生安装包验收。
