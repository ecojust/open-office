# 演示模板

打开演示文稿后，点击 PPT 功能区中“视图”右侧的“模板”打开模板栏；再次点击或点击模板栏的关闭按钮即可收起。模板入口仅出现在 PPT 功能区，不占用所有文档共用的顶部操作栏。内置模板随应用打包，可离线使用；自己保存的模板列在“我的模板”中。

## 内置设计

内置共 **100 套**，每套包含封面、内容和结尾三页，文字和几何形状均可编辑。顶部搜索框按模板名称即时筛选，支持中文名称、大小写及多个关键词；“我的模板”也参与搜索。可结合“全部 / 内置模板 / 我的模板”切换来源，清除关键词恢复完整列表。

## 保存与切换

- **将当前演示存为模板**：输入名称，保存整份演示文稿的幻灯片、内容、主题和页面尺寸。不会将当前文件标记为已保存；同名模板分别保留。
- **使用模板**：点击预览后弹窗确认，替换当前演示的全部幻灯片和内容；保留当前文件名及保存位置，产生未保存修改。一次撤销即可恢复切换前的文稿。
- **自动保存**：若桌面版已开启自动保存且当前文稿有本机保存位置，确认切换后的内容会按自动保存设置写回当前文件；确认框会明确提示。
- **删除模板**：仅可删除自定义模板，需弹窗确认；不影响已经打开的演示文稿。

模板名称最多 60 个字符，单个模板最多 40 MB。自定义模板保存在当前应用或浏览器的本地存储中；清除应用数据或浏览器站点数据会一并清除，请将重要模板另存为 PPTX 留作备份。桌面版和不同浏览器的模板库相互独立。

## 开发验证

原创内置素材位于 `public/presentation-templates/`。`python scripts/generate-presentation-templates.py` 使用相同绘图指令生成 PPTX 与 SVG 封面，行业目录与布局位于 `scripts/presentation_template_catalog.py`，开发环境需要 `python-pptx` 和 `fontTools`。这些依赖不进入应用运行环境。

`npm run test:browser:ppt-templates` 验证真实界面确认、切换、撤销、保存模板及全部 100 套模板的 Rust 导入/导出与重开；`npm run test:browser:ppt-templates-storage` 验证真实 IndexedDB 持久化和事务失败回滚。浏览器验证不能代替原生安装包验收。
