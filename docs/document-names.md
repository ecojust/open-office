# 文件名、项目名称与标签改名

九种工具使用统一的文档名称：文件名去掉扩展名，就是当前单份项目、日历本、笔记本或文档的名称。打开已有文件时，以实际文件名为准；标签显示完整文件名。

| 工具 | 名称对应的范围 |
| --- | --- |
| 文字文档 | 整份文稿 |
| 电子表格 | 整个工作簿 |
| 演示文稿 | 整份演示文稿 |
| PDF 工作室 | 整份 PDF |
| 笔记本 | 整个笔记本 |
| 画布 | 当前画布 |
| 代码图表 | 当前图表 |
| 计划排期 | 当前项目 |
| 日历便笺 | 当前日历本 |

例如，项目名称为「秋季发布」，对应文件为 `秋季发布.ooschedule`；日历本「工作记录」对应 `工作记录.oocalendar`。笔记本里的页面与分区、表格里的工作表，以及文档正文标题仍可独立命名。

## 修改名称

双击顶部标签标题，或让标签标题获得键盘焦点后按 **F2**，打开「修改名称」对话框。只输入名称，扩展名固定显示在右侧；点击「确定」应用，点击「取消」放弃此次输入。

修改后，标签与顶层项目名称同步。在排期的项目设置、日历本设置或笔记本名称入口改名，也会同步标签。名称需符合文件名规则，不能包含路径或系统保留字符。

## 保存与另存为

确定名称后，先更新当前编辑状态；点击「保存」或完成自动保存时，再更新磁盘文件名。桌面端已选择位置的文件会在原目录改名，同名文件不会被覆盖。遇到名称或文件冲突时会提示，当前修改仍保留，可换名或另存为。尚未保存的新文档首次保存时需要选择位置。

浏览器版保存会按新名称下载文件，无法修改此前打开的源文件。

同格式「另存为」保存到新文件后，当前标签跟随新文件和新名称；导出 PDF、图片、CSV 等副本则保留当前文档的名称与保存位置。

## MCP

文档名称修改后，原先开启的 MCP 会话会停止。需要继续使用时，点击当前文档的 MCP 按钮重新开启，使服务中的文档名称与界面一致。
