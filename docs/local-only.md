# 本地办公范围

更新日期：2026-10-13。

> 历史范围说明：下文的旧办公内核、命令屏蔽实现与发布检查记录对应 2026-10-13。该内核及 `public/office/offline-policy.js` 已移除；当前文字、表格、演示分别使用本地 WordCraft、GridCraft、DeckCraft，PDF 保留本地后端。当前架构和构建入口见 [README](../README.md) 与[开发文档](development.md)，下文旧内核命令及测试结果不作为当前实现或验收依据。本地文档与云服务的范围区分继续适用。

Open Office 是独立安装、本机处理文件的办公应用。后续功能对照和兼容验收只针对本地文档能力。以下服务永久排除，不作为待补齐差距：

- 账户登录、账户同步、云盘与远程文档打开或保存。
- 云端共同编辑、共享链接、协作通知、云版本历史。
- 云 AI、联网生成或改写、在线翻译、听写及内容分析服务。
- 在线素材和模板服务、远程音视频、需要联网的数据与计算服务。

不会通过接入其他厂商的云服务实现上述功能。本地批注、修订、保存冲突检查，以及文件中已有的文字、公式、链接和元数据属于不同能力，按文档格式逐项验收。

## 离线运行与文件处理

安装包包含办公内核、中文字体、PDF.js 和本地 PDF 处理进程。文字、表格、演示的编辑与保存由随包的 ZetaOffice／LibreOffice WASM 处理；PDF 编辑使用本地 PyMuPDF。最终用户不必另外安装 Office、LibreOffice 或 Python。

桌面应用的回环地址用于向自身的 WebView 提供随包资源，不是远程文档服务。打开和保存使用本机文件选择器；本地文件摘要检查和原子替换继续保留。宏和自动外部链接更新禁用，演示中的外部媒体不会自动下载。

开发和构建准备时会下载已固定版本及摘要的引擎、字体与依赖。这与安装后的文档处理分开：开发服务器的测试桥、发布检查和构建下载不属于产品云功能。操作系统自身的联网行为也不等同于应用提供云服务。

## 内核入口与验证边界

中文工作台不提供账户、云盘、云协作或云 AI 入口。发布后的源码另在 `public/office/offline-policy.js` 实现精确命令清单：限制远程打开/保存、邮件与共享、在线模板/帮助/反馈/更新、超链接执行和外链刷新；主线程和工作线程的资源传输只允许同源本地资源。内核配置、菜单/工具栏/右键菜单清理及运行时命令检查共同生效，已有宏不执行与外链不自动更新的导入策略继续保留。

`TemplateManager`、`EditLinks`、`ManageLinks`、`LinkDialog` 是混合本地与远程功能的管理入口，本轮整体关闭，因此暂不提供它们附带的本地模板库管理和本地外链编辑。不能据此宣称完整保留第三方内核的全部本地功能。

本地拼写检查、自动格式、目录更新，以及超链接文字编辑、复制、删除和文件中的链接元数据保留。这些功能不能仅按命令名含有“Online”“Send”“Update”就整体禁用。

本轮对固定运行包的 577 份 UI XML 作了实际离线审计，清理 247 处受限入口，清理结果中受限命令剩余 0；相关 Node 合同检查通过。首轮 22 份真实文档还分别读取原生菜单、配置及受限 dispatch 状态，确认本地保存入口保留，受限命令不可执行；该轮 129 次保存过程中记录的外部网络请求与页面异常均为 0。详细范围见[复杂文档回归](compatibility-results.md)。这些证据不能视为所有平台或任意文档的完整网络审计，新版安装包仍须独立验证。

本页不作“任意文件在所有平台均绝不发起网络请求”的未经验证承诺。离线运行、服务命令限制、受控文件保存及本地格式兼容分别测试；不能用其中一项通过代替其余项目。
