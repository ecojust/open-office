# 本地办公范围

Open Office 在本机打开、编辑和保存文档。文字、表格、演示与 PDF 都使用随安装包分发的本地 Rust/WASM 编辑器；安装包包含字体和渲染资源，无需额外的办公软件或 PDF 处理进程。

笔记本使用本地 TypeScript 结构化模型，以 `.oonote` 保存分区、页面、富文本、待办和内嵌图片，详见[笔记本说明](notebook.md)。0.12.0 的功能变化见[更新说明](releases/0.12.0.md)。

## 文件与服务范围

- 顶部工具栏提供统一的新建、打开、保存、另存为、导出和打印入口，操作属于当前文档标签。
- 七个子软件均提供打印内容：文字、表格、演示与 PDF 使用导出的 PDF 页面，笔记使用当前页，画布和代码图表使用完整画面。macOS 调用系统打印，Windows 的 PDF 会打开独立打印预览；图片和字体准备失败会显示提示。Linux 桌面暂未接入系统打印。打印不会把文档标记为已保存。
- 文档标签保留独立会话和未保存状态。文件写入成功、导出快照匹配后才更新保存基线；单个和批量关闭未保存文档都需要确认，可一次性放弃修改。
- 桌面版打开 DOCX、XLSX、PPTX、PDF 或 OONOTE 后保存回原文件；需要副本时另存为。CSV/TSV 转换另存为 XLSX，POTX/PPSX 转换另存为 PPTX，不覆盖原格式文件。
- 自动保存每 10 秒处理已选择本机位置的当前文档；到期遇到输入、草稿或弹窗时暂缓，随后短间隔复查并继续保存。顶部显示实际保存状态；新建和格式转换仍需先手动保存，后台不会弹出选文件窗口。
- 产品不提供账户同步、云盘、云端协作或局域网共享编辑。
- 产品不提供云 AI、在线翻译、听写、联网内容分析、在线素材或模板服务。
- 文件中的现有批注、修订、公式、链接和元数据按具体格式处理；它们不等同于云服务。

## 离线运行与验证

桌面应用的本机地址用于向自身 WebView 提供随包资源。打开和保存使用本机文件选择器；文档内容由本地编辑器处理。宿主负责保存冲突检查和原子替换。宏与自动外链更新不作为本版本的可执行功能，外部媒体不会自动下载。

开发准备时可下载固定版本的工具链、字体和依赖。构建下载、测试服务器与发布检查不属于安装后的文档服务。独立兼容验证可使用额外工具，这些工具不作为产品内核分发。

离线资源、文档会话、文件保存、格式兼容及原生安装包需要分别验证。历史报告不能自动证明当前源码或所有平台的行为。当前构建和验收入口见[开发文档](development.md)，PDF 范围见[PDF 能力说明](pdf-capabilities.md)。

旧版内核的命令清单、0.4.0 发布记录和测试数量保留在[历史范围说明](history/local-only-0.4.md)，仅用于追溯。
