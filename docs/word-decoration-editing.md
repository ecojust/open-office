# 页眉、页脚的普通文字修改

页眉、页脚侧栏现在只替换实际改变的普通文字片段，不再把整个区域写回为纯文字。原生字段、超链接和相邻文字格式留在当前文档中，导出时不回填原始文件。

## 可编辑范围

- 修改必须位于同一个原生普通 Text 片段内；片段不能带超链接。
- 检查完整区域最多 64 段、128 片段、5000 字，并与原生预览文字一致。
- 以原生片段起点创建光标；移动后再次核对前缀和选中文字，核对完成才执行一次局部替换。
- 纯插入携带该片段的一个原字符，避免继承邻接格式。不能跨格式、字段、链接、书签或对象边界。
- 新增、删除或替换段落/软换行均拒绝。无法确认的原生结构也拒绝，并保留输入供用户还原或在画布中编辑。

PAGE 等字段的显示结果、链接文字、跨格式修改仍须在画布中操作。这不是完整字段编辑器，也没有增加首页/奇偶页或复杂页样式编辑能力。关闭页眉/页脚仍会删除整个区域，原有明确确认与提示保持。

## 验证

`tests/writer-tools.test.mjs` 覆盖页眉与页脚的局部修改、字段/链接保护、格式交界、零宽对象、检查预算、Unicode 游标一致性，以及单一 Text 片段内的七类软换行拒绝。Writer 定向测试共 43 项通过。

`tests/compatibility/word-decorations/rich-decorations.docx` 是内部生成的测试文档，含红色加粗标签、蓝色斜体文字、真实 PAGE 字段、绿色超链接和紫色尾文字。链接仅作为元数据检查，不进行访问。

真实界面回归入口为 `tests/browser/word-decoration-ui.cjs`；独立 DOCX XML 核对入口为 `tests/browser/audit-word-decorations.py`。结果保存于 `test-results/decoration-word-followup/`。原生诊断先证明 `Report` → `Review` 后页脚 XML 除指定文字外完全一致；最终界面回归 12 项通过、0 页面运行错误，覆盖实际侧栏、撤销/重做、五类拒绝、DOCX/ODT 导出及重开。

独立文件核对 62 项通过：所有 6 个页眉/页脚 part 在归一化两处预期改字后与同引擎基线一致；拒绝操作前后 XML 与链接关系一致；DOCX 重开和经 ODT 转回 DOCX 后字段、链接和各可见文字格式保持。报告中的产品源码散列与本轮冻结文件一致。

首次文案匹配错误保留在 `ui-report-initial.json`；重开时测试未切回“开始”标签而等待其专属控件的失败保留在 `ui-report-reopen-selector.json` 和对应截图。两处仅修正测试，最终结果见 `ui-report.json` 与 `independent-decoration-audit.json`。

这些有边界的样本验证不代表任意复杂页眉、域或排版均可无损编辑。
