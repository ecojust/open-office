# Open Office PDF 能力与验证边界

本页描述本仓库的 PDF 编辑器，不能据此宣称与 Microsoft 365 或 Adobe Acrobat 全功能一致。PDF 是固定版式文件格式，Microsoft 365 中最相关的参照是 Word 的 PDF 导入转换，以及各 Office 应用的 PDF 导出。

本页描述[已公开发布的 0.4.0 测试版](https://github.com/ecojust/open-office/releases/tag/desktop-v0.4.0-38348938454)（prerelease）。下列能力按具体文件操作验收；浏览器、PDF 后端和桌面安装包是不同的验证层级。

**发布后的源码更新：**应用永久提供本地办公，不提供账户、云盘、云协作或云 AI。此次范围说明与云服务入口策略尚未打包发布；以下 0.4.0 证据不能自动覆盖新源码。详见[本地办公范围](local-only.md)。

2026-10-14 的后续源码另外加入[批注管理](pdf-completion.md)及[简单表单填写](pdf-form-filling.md)。后者支持可核实的 AcroForm 普通文本、多行文本和独立复选框；表单设计、XFA、脚本联动、单选组及下拉字段编辑仍未实现。下方发布版能力和历史测试保持原版本口径。

同日后续源码也加入[正文替换与交互对象保护](pdf-text-object-protection.md)：替换区与表单、批注或链接重叠时拒绝操作，编辑页存在待处理涂抹时也拒绝，避免误保留旧字段值或连带删除其他区域。

## 与 Word PDF 编辑的区别

Microsoft 官方说明：Word 打开 PDF 时会生成副本，将内容转换成可供 Word 显示和编辑的格式；以文字为主的 PDF 效果较好，复杂排版和扫描稿可能不能保持原有格式。修改后可以保存为 Word 文档或 PDF。

本项目使用 **PDF.js 显示、PyMuPDF 1.28.2 修改真实 PDF 页面**。既有 PDF 在 PDF 工作区内编辑，不经过 Word 重新排版；目前没有 PDF 转 DOCX 功能。文字编辑是在所选区域删除原文字并写入替代文字，适合合同字段、短段落和局部修改；不是跨页正文自动重排。内嵌原字体无法继续使用时采用本地 CJK 字体，字形与断行需要用户核对。

## 当前能力

| 功能 | 实际行为 | 边界 |
| --- | --- | --- |
| 原文编辑 | 选中可提取的文字区域，真正移除原字并写入新字；中文可保存回读 | 扫描图、轮廓文字不能直接编辑；不承诺原字体和复杂排版完全保真 |
| 新增内容 | 区域内新增文字、PNG/JPEG 图片、高亮和手写批注 | 手写签名是墨迹批注，不是数字证书签名 |
| 页面管理 | 旋转、重排、删除、提取和追加 PDF 页面 | 至少保留一页；合并加密文件需要明确允许生成未加密副本 |
| 撤销/重做 | 恢复实际 PDF 字节快照 | 最多 8 个快照，累计解码后 48 MiB；大文件可能减少可撤销步数 |
| 全文搜索 | 搜索各页可提取文字，定位匹配页面 | 不能搜索图片中的文字，不包含 OCR |
| 页码 | 全部页面或勾选页面；数字、数字/总页数、中文三种格式；页眉/页脚左中右六个位置 | 使用当前文档的实际页序；已有页码不会自动识别或移除；页码是写入时的静态内容，之后调整页序不会自动重算 |
| 文字水印 | 全部页面或勾选页面；居中横排中文/拉丁文字，可选字号、颜色和不透明度 | 单行，最多 120 字；过长时整次操作拒绝并保留原文档；不含图片水印和斜排水印 |
| 书签目录 | 读取既有层级书签并跳转到本地目标页 | 最多显示 2,000 项、20 层；外部文件/网址及无效目标不会自动打开；暂不新增或编辑书签 |
| 加密与签名文件 | 检查打开密码和权限；修改时保留原加密设置；签名文件先明确选择编辑副本 | 不验证签名证书信任链，修改副本不再有原签名完整性保证 |
| 保存 | 保存实际 PDF 文件，支持重新打开验证 | 编辑引擎限制 40 MiB、500 页；超出输出大小的操作整次拒绝 |

页码和水印保留页面原有旋转、裁切范围及内容，支持 `/Rotate` 为 0/90/180/270 的页面。水印是透明页面内容，不会阻止复制，也不能隐藏或安全删除敏感信息。应用后可在当前会话撤销；保存并重新打开后不会自动保留历史快照。

桌面版包含本地编辑引擎，不向远端上传文档。普通生产网页提供 PDF 预览；本地开发服务器的编辑桥仅用于开发与自动化验证。

## 明确未实现的能力

- OCR、扫描页文字识别、PDF 转 Word/Excel、跨页自动重排、完整字体替换与印前色彩管理。
- AcroForm/XFA 表单设计和填写、PDF JavaScript 工作流、数字证书签署与长期验证。
- 自动修复 PDF/UA 标签、阅读顺序和复杂文档无障碍问题。
- Acrobat 全套本地动作、完整本地审阅、审计和版本管理。

这些能力不能因引擎有底层 API、文件能打开或界面存在菜单就算已支持；需要独立实现并以可保存、可重新打开的文件验收。

## 永久排除的云功能

云端转换、云 AI、在线共同审阅、账户同步、云盘保存和共享链接不属于产品范围，不作为待实现能力。PDF 的搜索、编辑、批注和导出使用本机引擎处理；保留在文件中的链接或云服务元数据不代表本应用会访问相应服务。

## 本轮验收

`pdf-backend/tests/test_stamps.py` 使用真实 PDF 写入、保存、重新打开，检查四种旋转和非零 CropBox 的页码位置与方向、中文页码、所选页水印、透明度、书签保留、文字溢出的事务回滚、权限拒绝及签名副本要求。原 `test_engine.py` 回归原文替换、图片、批注、页面操作与加密处理。

`tests/browser/pdf-ui.cjs` 通过真实 Vue 按钮调用本地 PyMuPDF，验证书签跳转、页码和撤销/重做、水印保存与独立回读，再执行既有 PDF 编辑、保存、密码和小窗口回归。报告默认写入 `test-results/pdf-ui/`，复跑会覆盖该路径，引用时须核对运行版本与实际状态；浏览器验证不代替每个平台安装包中的原生对话框验证。

发布提交 `4788fec61d97d45bd8627e7fd7e3a4fa3bbcbe21` 的[构建 38348938454](https://github.com/ecojust/open-office/actions/runs/38348938454) 全部通过：Windows 与 Apple Silicon 最终应用、同一原封 Intel DMG 的 Rosetta 运行均完成真实 GUI 验收，包括 PDF 中英文原文替换、独立重新读取，以及 Writer／Calc／Impress 导出 PDF 的检查。原生门槛不等同于在每个平台完整执行上述所有 PDF UI 用例；Rosetta 通过也不是物理 Intel GPU 实测。

同一发布提交的无探针 Word／Calc helper、独立 PDF 回读和最终完整中文 UI 均通过；UI 为 10 项检查，页面错误与 HTTP 失败为 0。完整测试通过 242 项 Node 回归和 28 项真实 Python PDF 测试。以上记录仅覆盖列明的样例，不能称为 Microsoft 365 或 Acrobat 全功能兼容。
