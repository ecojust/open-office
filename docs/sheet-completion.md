# 电子表格：填充、选区汇总与已有规则

本轮保留本地表格内核与已有 XLSX / ODS 读写能力，补齐日常编辑中的三个完整操作路径。

## 已实现

### 向下、向右填充

在“数据”工具栏选择方向，先显示覆盖目标内容及格式的确认说明。向下以选区第一行为来源；向右以第一列为来源。原生 `XCellSeries.fillSeries` 的 SIMPLE 模式负责复制类型、格式和计算引用，不使用字符串替换公式。

一次最多 10,000 格。保护工作表、非连续选区、合并单元格及数组公式在写入前拒绝。普通单格选择不能填充。操作参与原生撤销/重做。

### 选区汇总

连续选择 2–10,000 格时，底部显示非空计数、求和和平均值，提示中另有数值计数、最小值和最大值。默认只统计可见行，可点击“可见行 / 含隐藏行”切换；被筛选隐藏的行也服从该开关，隐藏列仍参与统计。

按真实内核数据类型计算，不将 `001` 之类文本数字转换成数值；公式错误单列计数并排除求和；计算出空字符串的公式仍属于非空单元格。日期按内核数值序列参与计算，不强行转换为日期显示。无数字时平均、最小、最大显示“—”，和为 0。超出有限数值的结果显示“—”。汇总为只读操作，不标记文档修改。

读取有延迟合并和请求版本检查。切换文档、工作表、选区、修订或隐藏行口径后，过时结果不显示。

### 已有规则回读

“条件格式”和“数据有效性”面板增加只读的规则查看区，展示选中单元格的验证类型、公式、是否允许空白及条件格式列表。读取不会自动覆盖编辑输入，也不会修改文档。

多个单元格可能规则不同，本轮只允许单格回读并明确提示原因。高级已有规则可以只读显示，现有新建规则的支持范围维持整数、小数、列表等，不将未支持规则强行转成默认整数规则。
