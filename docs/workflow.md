# 画布与代码图表

Open Office 的工作台和顶部「新建」菜单提供「画布」「代码图表」两个入口。新建、打开、保存、另存为、自动保存、撤销和重做使用软件共用的操作栏；各文档在独立标签中编辑，主题跟随全局设置。

## 画布

画布适合流程图、自由绘图、白板和方案整理。可以插入图形、文字、便签、图片和分区，拖动调整位置与大小，为图形添加绑定连线。画笔提供多种笔触；选择多个元素后，可以组合、对齐、均匀分布、调整层级或锁定。

连线默认使用直线，画布默认开启网格吸附，可在操作栏和画布设置中调整。选中矩形后，右侧属性栏可设置圆角半径，默认 0（直角），最大为短边的一半；保存、复制和图片导出保留圆角。

工具栏最左侧为「连续作画」「选择」「拖动」三个互斥模式。连续作画会保留当前绘图工具，画完后可以继续绘制；普通绘图只画一次便返回选择。选择、拖动以及 V、H、Esc 快捷键会退出连续作画；按住空格临时平移不改变模式。这里的锁图标表示连续使用工具，元素自身的锁定仍在属性栏中单独设置。

「画布模板」提供流程图、白板、头脑风暴、四象限、看板和复盘布局。模板中的内容可以继续编辑；「全局线条」可以统一线型、颜色和整洁或手绘效果。滚轮平移画布，按住 Ctrl 或 Command 滚动缩放。

删除所选元素或使用橡皮擦删除时，会先弹窗确认。撤销可以恢复最近的内容修改。

## 代码图表

在左侧输入图表源码，右侧自动更新预览；语法错误会显示提示。源码中的光标位置或选区可以关联高亮图中的对象。

「图表模板」提供 22 类图表、46 个示例，涵盖流程、时序、类、状态、实体关系、甘特图、思维导图、时间线、看板及多种统计图。「图表风格」提供十种视觉风格。编辑器支持这些类型的常用语法子集；未支持的语法会显示具体提示。

源码始终保留在当前文档中；转换为画布会创建独立的可编辑文档，之后两份文档可分别修改。即使源码暂时存在语法错误，也可以保存当前内容，之后继续修正；图片导出需要先生成有效预览。

## 文件与导出

使用 `.owflow` 保存完整的可编辑内容。文件中的格式标识及部分字段保持兼容，已有文档可继续打开。图形 XML、白板 JSON 和文本图表源码可导入；转换后请检查布局和兼容性提示，再保存为完整文档。

桌面版首次选择保存位置后，可以在保存按钮旁开启自动保存。旁边显示下一次保存的倒计时；输入法组字、未确认的画布操作或弹窗期间会暂缓，完成后继续保存。浏览器版使用保存按钮下载文件。

支持导出 SVG 矢量图和 PNG 图片。导出图片用于分享或插入其他文档；继续编辑请保留 `.owflow` 文件。导入内容和绘图资源在本机处理，不需要连接额外的服务。

顶部「打印」输出当前画布或代码图表的完整画面，采用横向页面，不包含编辑工具栏。打印前会等待图片和字体就绪；代码存在语法错误时需先修正。打印不会改变文件的保存状态。
