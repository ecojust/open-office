# 画布与代码图表

Open Office 的工作台和顶部「新建」菜单提供「画布」「代码图表」两个入口。新建、打开、保存、另存为、自动保存、撤销和重做使用软件共用的操作栏；各文档在独立标签中编辑，主题跟随全局设置。

## 画布

画布适合流程图、自由绘图、白板和方案整理。可以插入图形、文字、便签、图片和分区，拖动调整位置与大小，为图形添加绑定连线。画笔提供多种笔触；选择多个元素后，可以组合、对齐、均匀分布、调整层级或锁定。

在空白处拖出选框后，点击选区旁的「组合」按钮可把多个图形组合起来，也可以通过右键菜单或 Ctrl / Command + G 组合；增加 Shift 可取消组合。点击任意组合成员会选中整组，按住 Alt 点击可单独编辑成员。

多选和组合的包围框提供四个角上的缩放控制点，沿对角方向拖动可围绕对角端点等比缩放，图形、文字和笔触会一起调整。单个未旋转图形保留右下角自由调整宽高的方式；已旋转图形使用四角等比缩放。包围框右上方的旋转按钮每点击一次顺时针旋转 **5°**，多选时围绕共同中心旋转。锁定的图形或含锁定成员的组合需要先解锁。这些修改支持撤销、重做，并随 `.owflow` 文件保存。

「新建连线设置」位于「快捷图形」中，紧邻连线工具，可选择接下来连线的路径和箭头。连线默认使用直线，画布默认开启网格吸附，可在操作栏和画布设置中调整。选中矩形后，右侧属性栏可设置圆角半径，默认 0（直角），最大为短边的一半；保存、复制和图片导出保留圆角。

工具栏最左侧为「连续作画」「选择」「拖动」三个互斥模式。连续作画会保留当前绘图工具，画完后可以继续绘制；普通绘图只画一次便返回选择。选择、拖动以及 V、H、Esc 快捷键会退出连续作画；按住空格临时平移不改变模式。这里的锁图标表示连续使用工具，元素自身的锁定仍在属性栏中单独设置。

「画布模板」提供流程图、白板、头脑风暴、四象限、看板和复盘布局。模板中的内容可以继续编辑；「全局线条」可以统一线型、颜色和整洁或手绘效果。滚轮平移画布，按住 Ctrl 或 Command 滚动缩放。

点击「聚焦图形」按钮或在画布中按 **Home**，可快速回到图形中心，并保留当前缩放比例：有选择时聚焦选区，没有选择时聚焦全部内容。若需要让整张画布都显示出来，点击「适应画布」或按 **0**，会同时调整缩放比例和位置。

删除所选元素或使用橡皮擦删除时，会先弹窗确认。撤销可以恢复最近的内容修改。

## 代码图表

在左侧输入图表源码，右侧自动更新预览；语法错误会显示提示。源码中的光标位置或选区可以关联高亮图中的对象。

「图表模板」提供 22 类图表、46 个示例，涵盖流程、时序、类、状态、实体关系、甘特图、思维导图、时间线、看板及多种统计图。「图表风格」提供十种视觉风格。编辑器支持这些类型的常用语法子集；未支持的语法会显示具体提示。

源码始终保留在当前文档中；转换为画布会创建独立的可编辑文档，之后两份文档可分别修改。即使源码暂时存在语法错误，也可以保存当前内容，之后继续修正；图片导出需要先生成有效预览。

## 文件与导出

使用 `.owflow` 保存完整的可编辑内容。文件中的格式标识及部分字段保持兼容，已有文档可继续打开。图形 XML、白板 JSON 和文本图表源码可导入；转换后请检查布局和兼容性提示，再保存为完整文档。

桌面版首次选择保存位置后，可以在保存按钮旁开启自动保存。旁边显示下一次保存的倒计时；输入法组字、未确认的画布操作或弹窗期间会暂缓，完成后继续保存。浏览器版使用保存按钮下载文件。

支持导出 SVG 矢量图和 PNG 图片。导出图片用于分享或插入其他文档；继续编辑请保留 `.owflow` 文件。导入内容和绘图资源在本机处理，不需要连接额外的服务。

顶部「打印」输出当前画布或代码图表的完整画面，采用横向页面，不包含编辑工具栏。打印前会等待图片和字体就绪；代码存在语法错误时需先修正。打印不会改变文件的保存状态。

## MCP 画布变换

`canvas_edit` 支持 `rotate` 和 `scale` 操作。两种操作会展开指定成员所在的完整组合；组合中存在锁定成员时，整个操作会拒绝执行。`rotate` 的 `degrees` 默认 `5`，正数顺时针、负数逆时针，范围为 −360° 到 360°。`scale` 的 `factor` 为 0.01–100，按文档合法尺寸范围等比调整；可传入固定的画布坐标 `anchor: { x, y }`，省略时以选区中心为锚点。图形的 `rotation` 属性也可通过 `add`、`update` 设置，读取元素时保留规范化后的角度，省略代表 0°。

例如，将元素 `card-a` 所在的组合顺时针旋转 5° 后，以共同中心放大到原来的 1.2 倍：

```json
{
  "operations": [
    { "op": "rotate", "ids": ["card-a"], "degrees": 5 },
    { "op": "scale", "ids": ["card-a"], "factor": 1.2 }
  ]
}
```

同一次调用中的变更整体撤销；参数错误或存在锁定成员时，不保留前面的部分修改。

`canvas_select_elements` 的 `focus: true` 可在保持当前缩放的情况下定位选区；`ids` 为空时清除选择并聚焦全部图形。例如：

```json
{ "ids": ["card-a"], "focus": true }
```

如需自动缩放以显示整个画布，使用 `fit: true`。`fit` 与 `focus` 不能同时为 `true`；这些操作只改变视图，不修改文件内容。
