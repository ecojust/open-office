# 自动保存与浏览器工作区

保存按钮旁的自动保存开关属于全局设置。桌面版每 30 秒尝试保存当前文档，要求已经手动选择本机路径，且不涉及格式转换、首次导入保护、输入法组词或正在进行的文件操作。保存失败保留修改并延迟重试。切换标签不会丢弃其他文档的会话；非当前文档可在切回后自动保存。

## 使用 Server

1. 在桌面版点击顶部 **Server → 启动 Server**。
2. 复制本机或局域网访问链接，在浏览器打开。无需账户或配对码；持有链接即可访问工作区。
3. 从共享文档列表打开文档，也可以新建或导入文件。打开的文档停顿后会自动同步；通过 Server 面板查看和打开另一端新建的文档。
4. 使用客户端保存或另存为将文档写入本机文件。浏览器的保存按钮用于下载文件副本。
5. 停止 Server 或退出桌面应用后浏览器断开。重新启动 Server 会生成新链接，并恢复上次已经同步的工作区快照。

桌面应用需保持运行，两端需能够通过该地址连通。链接使用 HTTP，适合可信局域网；无需公网服务器。链接不授予桌面文件选择器或任意本机文件访问权限。

## 同步与冲突

约每 1.5 秒检查共享状态，输入停顿至少 1.2 秒且输入法已确认后同步。尚未确认的单元格、文本框、表单或对话框草稿会等待用户确认，后台同步和自动保存不会代替用户提交输入。上传完整的 DOCX、XLSX、PPTX 或 PDF 快照，不是逐字符协同编辑；较大文档的同步会更慢。更新会重新打开接收端文档模型，因此接收端的光标位置和撤销历史可能重置。

每次写入检查文档版本。两端同时修改时，当前内容保存为“冲突副本”，另一端的版本保留在原共享文档中；用户自行核对后整理。失败下载、解析或提交不会自动覆盖本地编辑。断网时可继续编辑，保持页面打开，恢复后自动重试；未同步的修改仅在当前会话内，关闭前请下载或保存。

同步成功表示客户端工作区快照已持久化，不等于原文件已经保存。新建及导入文件仍遵守首次另存保护；首次导入的原件不会被自动保存覆盖。共享快照位于客户端应用数据目录的 `browser-workspace/workspace.json`，不进入仓库。

单个文档上限 40 MiB，工作区最多 64 个文档、总计 64 MiB。每端同一类型最多同时打开 7 份文档，给接收更新时的内容校验保留空间。停止服务会保留已同步快照，关闭标签只关闭当前编辑会话。
