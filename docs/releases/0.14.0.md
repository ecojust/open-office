# Open Office 0.14.0 · 演示模板与编辑性能优化

本次更新加入演示模板库，减少切页和切换文档时的重复工作，并改进笔记布局、PDF 草稿处理和多文档标签栏。

## 更新内容

1. **10 套离线演示模板。** 每套包含可编辑的封面、内容和结尾三页。支持将当前演示存入“我的模板”；切换时确认替换全部幻灯片、布局和内容，可用撤销恢复。删除自定义模板需确认，不影响已打开的演示。
2. **更紧凑的笔记界面。** 左侧页面树只显示标题；区域块仅选中时显示边框和操作控件，点击空白处清空选择。无效长标题会保留为可编辑草稿，切换失败时不会丢失输入。
3. **减少编辑和切换等待。** 演示缓存最近访问的四页，只绘制可见缩略图，内容或字体变化时更新缓存。Word 跳过未变化共享内容的重复比较。切换文档标签保留实时模型、输入和撤销历史，不再为了切换导出整份文件；实际保存仍校验对应版本。
4. **修复 PDF 空批注阻挡保存。** 空白、未修改以及撤销或删除后残留的批注编辑状态不再被误认为待提交草稿。真正未完成的批注可从操作栏返回编辑、提交或确认放弃；删除、撤销后保留草稿与原批注的对应关系。
5. **固定工作台入口。** 标签栏左侧 Home 按钮以及右侧新建、全部关闭按钮保持固定，中间文档标签独立横向滚动，减少切换时的滚动跳动。
6. **更新 README 展示图。** 封面采用实际运行的五种工作区和更丰富的示例文档；截图版本与来源在旁附说明中标明。

## 验证与使用说明

本地全套 605 项测试通过；后续笔记草稿修复通过 19 项定向测试与类型检查。真实 Rust/WASM 浏览器回归覆盖 10 套模板导出重开、自定义模板、PDF 草稿、笔记和 Home；四种 Rust 编辑器分别与笔记本交叉切换的 29 项检查通过。浏览器文件接口替身不代替原生磁盘写入验收，也不表示五种引擎同时常驻已经验收。

默认三页演示在相同六次切页操作中的整页纹理上传由六次降为两次，后四次访问已见页面无需新增画布绘制。这说明重复工作减少，不代表所有文档的输入、拖动和滚动都已消除卡顿；详见[性能验证](../editor-performance.md)。

安装包发布要求 Windows x64、macOS ARM64、Intel 原包 Rosetta，以及 macOS 26 原包真实输入和完整编辑器验收全部通过。流程还运行本次新增的 Word 状态比较、演示模板与缓存、PDF 草稿 Rust 回归。原生验收不等于 macOS 26.5 的全部硬件、系统输入法和文件选择器行为验证；Intel Rosetta 验收不等于物理 Intel GPU 测试。

应用仍处于 Alpha。自定义模板保存在本机，不跨设备同步；开启自动保存时，应用模板后的内容会按既有规则保存回当前文件。复杂文档请核对保存后的内容和版式。当前未配置商业代码签名或 macOS 开发者公证；发布附件包含 Windows 安装程序、两个架构的 macOS DMG、对应源码及 `SHA256SUMS`。
