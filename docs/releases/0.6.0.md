# Open Office 0.6.0 · 轻量文字编辑器预览

提供 Windows x64、Apple Silicon Mac 和 Intel Mac 安装包，支持本机处理文字文档、电子表格、演示文稿和 PDF。安装包包含离线编辑资源、中文字体和 PDF 后端。

本版更新：

- 新增“轻量文字文档（预览）”入口，使用独立正文模型、编辑界面和 DOCX 读写模块。支持中文输入、基础文字格式、标题、对齐、缩进、段落间距、行距及撤销重做。
- 增加单／双下划线及独立线条颜色、上下标、单／双删除线、字符间距、字偶距、大写与小型大写显示、高亮、文字背景色和基线偏移；保留空段与段落标记的格式。
- 支持 A4、A5、Letter、Legal 和自定义纸张尺寸、独立纸张方向及四边页边距，并保留受支持设置的 DOCX 往返结果。
- 轻量文字的桌面 DOCX 解压、压缩与 CRC 校验接入 Rust 后台模块；复用已解析模型，减少导入时的重复工作。首次保存导入文稿时生成副本。
- PDF 增加普通下拉框和单选表单字段的填写与保存。
- 修正固定版本办公运行时的原生鼠标事件时间戳，改善表格编辑后再次点击与双击的部分场景；首次画面准备和工具栏操作仍有已知问题。

验证与发布：

发布前通过类型检查、865 项 Node 测试、83 项 Python 测试、12 项独立 Rust 包测试及完整前端构建。此前专项覆盖独立文字模型、界面操作、DOCX 编解码、真实 Rust CLI，以及固定 LibreOffice 版本的原件和保存重开对照；页面设置、段落间距及格式专项的范围见 `docs/independent-word.md`。性能记录区分输入、导入和包处理，不宣称所有操作加速。

发布流程要求三个平台的安装包全部构建成功，并通过规定的实际应用自检。新增检查会在加载 Office 引擎前，通过真实 Rust IPC 完成独立 Word 的两轮文稿读写、格式保留和无效输入拒绝；随后执行原有工作区及 PDF 检查。Windows x64 在 Windows Server 2022 验证，ARM Mac 在 macOS 15 验证；Intel 包原生编译后，将未修改的 DMG 转移至 ARM Mac，通过 Rosetta 验证 x64 应用及 PDF 进程。详细结果保留在对应 Actions 运行记录中。

已知限制：

- 轻量文字仍为预览，仅接受已实现的 DOCX 子集，尚未支持复杂分页、表格和图片。完整文字工作区仍使用现有办公引擎；此版本并非纯 Rust 办公套件，XML 处理、文档模型和界面仍由 TypeScript / Vue 实现。
- 不保证任意 Microsoft Office 文档无损兼容。原生 LibreOffice 对照限定固定版本及测试样例，不等同于全部 Word 版本、输入法或原生 WebView 的专项验证。
- 表格首次打开时，工具栏和画布可能晚于模型显示，存在短暂位置不一致；初始工具栏交互的部分回归仍未通过。不能将模型就绪视为全部交互已验证。
- 复杂演示动画、SmartArt 结构与布局编辑、部分新公式等仍有既有限制；PDF 暂无 OCR 和证书数字签名编辑。
- Intel 包的 Rosetta 检查不等同于真实 Intel GPU 或所有系统版本测试。新增 Rust IPC 自检验证包处理模块，不代表全部轻量文字 UI 和文件对话框已在三个平台逐项验证。

macOS 安装包采用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 安装包没有商业代码签名。发布附件包含三种安装包、对应提交的源码 ZIP 和 `SHA256SUMS`；诊断报告保留在 Actions artifacts。
