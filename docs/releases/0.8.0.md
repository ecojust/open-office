# Open Office 0.8.0 · WordCraft 文字编辑器 Alpha

本版将默认文字工作区替换为 WordCraft 的 Rust 文档内核与完整 egui 功能区、正文画布。固定上游提交为 `3292ba05d3c15c003823be6849e87a1c6e205242`；这是对开源编辑器源码的本地集成，不是从零实现的完整 Microsoft Word 引擎。

**当前状态：浏览器开发验收通过，三平台安装包待构建验证，尚未公开发布。** 本轮工作流使用 `platform=all`、`publish=false`，构建 Windows x64、macOS ARM64 与 macOS Intel 包；产物和结果以本轮 Actions 记录为准。公开发布需要后续完成全部必要检查。

## 主要变化

- WordCraft 负责 DOCX 解析、正文模型、编辑命令、撤销重做、排版与绘制；桌面 WebView 和浏览器均运行随应用分发的本地 WASM。Vue/Tauri 负责标签页、原生文件操作和保存保护。
- 默认文字工作区开放 DOCX 新建、打开、编辑、保存，以及 PDF 副本导出；复用文字与段落格式、列表、表格、图片、页面设置、页眉页脚及审阅等上游工具入口。完整功能区不代表每个功能已经验证。
- 多标签保留各自文档和历史。导入 DOCX 首次保存生成副本；失败打开保留当前正文与历史，保存只有在交付成功且版本仍匹配时才更新保存状态。PDF 导出不清除 DOCX 的未保存修改。
- 接入中文与部分单色 emoji 字体，修复浏览器连续输入、输入法更正、切换标签时的输入归属和重复粘贴。真实画布操作及导出文件由独立检查器验证。

文字兼容入口和电子表格仍使用原办公引擎，演示与 PDF 保留各自实现。0.7.0 的基础 Rust 内核和旧轻量文字入口仍留作兼容／历史路径，旧 IPC 成功不能证明新默认 WordCraft 界面通过。

## 已完成的开发验证

2026-10-15 的集成冻结快照通过 Rust/WASM 构建、产物摘要检查、前端类型检查、生产构建及 911 项 Node 测试。实际 WordCraft 浏览器验收通过 9 组检查；核心包含 84 次真实 host 请求、60 次成功命令、6 次输入法更正原子拒绝和 1 次未知命令拒绝。

独立完整 DOCX 原件与外部应用重存版本各完成两轮保存重开。10 份核心导出工件和 11 条 UI 文件记录用于独立 XML/PDF 核验，覆盖正文格式、列表、表格、图片、页眉页脚、PAGE 域，以及中文和 emoji。实际画布验证覆盖连续 Unicode 输入、输入法保存、撤销重做、粗体／斜体／下划线按钮、同会话普通与纯文本粘贴对照、多标签和失败导入保护。没有观察到外网、旧 Office runtime 或旧文字核心请求。

这些结果对应集成快照；0.8.0 的版本元数据与新增桌面检查仍需随本轮构建复核。完整证据、摘要和复现方式见[WordCraft 集成说明](../wordcraft-integration.md)。本轮未执行新增 Rust 代码的原生 `cargo test`，实际 WASM 验收不替代原生单元测试。

## 安装包验证要求与限制

新的桌面检查已接入安装包必检流程：加载默认 WordCraft 的 WASM 与画布，验证合成中文／emoji 输入、Rust 格式命令、DOCX 导出与保存回执、过期保存和无效打开保护、重开与资源释放，并独立读取导出文件；同时核对安装目录与 WebView 实际获取的 JS／WASM 资源摘要。Windows 使用真实安装目录，macOS ARM64 使用对应应用，Intel 包按原包转移至 ARM Mac 后通过 Rosetta 运行。缺失或失败的必要报告不能计为通过；浏览器、旧 Rust IPC 和编译成功均不能代替这些检查。实际安装包结果仍待本轮 Actions。

该自动检查不包含物理输入法、系统剪贴板、原生文件对话框或磁盘交付；保存断言只覆盖导出 DOCX 字节和编辑器保存回执。这些边界与此前 Chromium 的输入法／剪贴板验收分别记录。

WordCraft 上游仍为 Alpha。复杂 DOCX、浮动对象、图表／SmartArt、特殊字体和与 Microsoft Word 的分页一致性不保证完整兼容；尚无性能提升对照结论。跨标签／跨应用富文本剪贴板未接通，系统剪贴板目前传纯文本，同会话可在文本匹配时复用内部格式片段。Chromium 的输入法测试不等于物理系统输入法验收，Rosetta 也不等于真实 Intel 显卡测试。

macOS 仍使用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 未配置商业代码签名。WordCraft、craft-ui、字体和其他依赖的原始许可及来源随应用保留；发行包含多种许可证组件，详见[第三方许可清单](../../THIRD_PARTY_NOTICES.md)与[集成分发许可](../../DISTRIBUTION_LICENSE.md)。
