# Open Office 0.12.0 · 本地笔记本与文件操作优化

本页记录 0.12.0 的更新内容与验证要求。安装包通过原生验收后发布，可下载版本和平台以[发布页](https://github.com/ecojust/open-office/releases)为准。

## 主要变化

1. **打开原文件，直接保存。** 桌面版打开 DOCX、XLSX、PPTX、PDF 或 OONOTE 后，“保存”写回已打开的文件，不再自动生成副本。“另存为”仍可选择新位置；外部修改和文件身份检查保留，并防止另存为覆盖其他打开标签的文件。CSV/TSV 转换另存为 XLSX，POTX/PPSX 转换另存为 PPTX，原格式文件保留。
2. **移除 Server。** 删除浏览器共享面板、共享快照、同步接口和局域网监听服务。桌面应用继续使用本机资源服务加载自身界面，不提供远程共享编辑；原生自动保存及其验收门禁保留。
3. **新增本地笔记本。** 使用 `.oonote` 保存分区、页面、富文本、列表、待办和 PNG/JPEG 图片，支持搜索、撤销重做及当前页面打印。笔记本由本地 TypeScript 结构化模型驱动，与四套 Rust 编辑器共用文件操作、主题和文档标签，详见[笔记本说明](../notebook.md)。
4. **修复主页文档列表。** “正在编辑”列表较长时独立滚动，避免挤出主页操作区；长文件名省略显示并可查看完整名称。
5. **支持批量关闭。** 主页和标签栏增加“全部关闭”。有未保存修改时集中列出文档，可选择全部保存、全部不保存或取消；退出窗口也使用批量确认。
6. **整理 PDF 操作栏。** 常用编辑与视图操作直接放到操作栏，其他已接通的功能归入高级菜单。可视签名和图章保留直接按钮，删除操作弹窗确认。可视签名不等同于数字证书签署，完整范围见[PDF 能力说明](../pdf-capabilities.md)。
7. **统一字体和图标。** 全部界面共用本地 Inter 与文泉驿微米黑字体，统一控件字号和原创 SVG 图标尺寸。笔记本复用相同格式图标，PDF 图标强调色独立适配深浅主题；文档字体和内容编辑预览保持独立，详见[界面规范](../interface-style.md)。

## 保存与使用边界

自动保存继续使用 30 秒间隔，仅处理已选择本机位置的当前文档。新建和需要转换格式的文档先手动保存；后台不弹出文件对话框，不强行提交尚未确认的输入草稿，也不会用旧回执清除写盘期间的新修改。浏览器开发预览通过下载交付文件，不具备桌面原文件写回能力。

`.oonote` 是本应用的结构化笔记格式，文件上限 16 MiB、单张图片上限 4 MiB，不承诺兼容其他笔记软件的专有文件。应用继续处于 Alpha，复杂文档的格式往返、字体和版式可能有差异，需要核对保存结果。

## 验证与发布要求

功能更新已通过生产构建和 25 项真实文件读写测试；界面统一后的 Node 回归为 545 项，全部通过。笔记本通过 10 组 Chromium 界面检查，覆盖下载重开、待办、图片、删除确认及批量关闭。PDF 操作栏通过 6 组实际界面检查，覆盖 320–1280 像素宽度、工具与视图切换、手绘签名、图章、删除确认、撤销和导出重开；独立 PDF 解析确认签名与图章实际写入文件。两套界面的截图也已复核。

字体与图标更新后，四套 Rust 编辑器和网页生产构建均通过。六个界面通过深浅主题、1440/800 像素窗口检查，主页另含 480 像素检查，共 19 张截图；本地字体实际加载、SVG 属性、控件边界、卡片对齐及切换外观不改变文档历史均有验证。字体覆盖检查包含全部 1389 个中文界面字符。共享字体源码另通过 2 项 Rust 测试，确认两种界面字重可绘制中英文，并保留既有文档字体数据和专用字体族。

最后补齐字体测试的纹理输出清理后，完整构建再次通过；四套编辑器的全部运行资源与截图及 PDF 编辑验证时逐字节一致，40 个受检界面源码和字体资源哈希未变，发布目录也与最终清单一致。关联检查记录在 `test-results/office-ui-style/final-artifact-comparison.json`。

PDF 浏览器编辑回归在字体与图标更新后再次通过，包含真实中英文输入、全局保存下载、保存回执、后台导出保留草稿与焦点，以及未完成输入被明确丢弃后的双标签隔离。工具切换后的测试点击改为等待实际页面布局，原有断言和输入提交时限保持不变。

以上本地检查不代替原生安装包验收。发布门禁要求 Windows x64、macOS ARM64、Intel 应用和 macOS 26 全部通过，使用同一提交的安装包检查四套 Rust 编辑器的编辑与文件导出。新增笔记本原生检查在安装后的 WebView 内完成标题和正文输入，通过顶部保存按钮写回隔离临时文件，核对文件身份与保存回执、独立解析磁盘读回内容，再关闭并用新会话重新打开；失败路径也显式清理临时文件。复用历史构建发布时同样要求笔记本报告，缺失报告不能发布。

原生自动保存门禁使用正常 30 秒计时器、真实文件写入与读回、独立 DOCX 解析、编辑器重开和焦点/回执检查；Server 检查随功能移除，不替代或取消自动保存检查。临时文件使用隔离测试入口授权，未覆盖系统文件选择器。笔记本输入通过原生 WebView 的 DOM 完成，不代表物理键盘或系统输入法验收；macOS 26 原有四套编辑器真实系统输入门禁继续保留。Chromium 测试也不替代原生 WebView 验收。

Intel 安装包的 Rosetta 验收不等同于物理 Intel GPU 测试。当前未配置商业代码签名或 macOS 开发者公证；安装包和源码、校验文件仅在实际发布后以发行页为准。
