# Open Office 0.25.0 · 统一文档名称与画布变换

本版统一九种工具的文件名与文档名称，并为画布增加组合操作入口、四角缩放、步进旋转和快速聚焦。

## 更新内容

- **文件名对应单份文档名称。** 排期文件对应项目名，日历文件对应日历本名，笔记文件对应整个笔记本名。双击标签标题或聚焦后按 F2 可改名，保存或自动保存时同步磁盘文件名，扩展名保持不变；遇到同名文件会提示，保留当前编辑内容。浏览器版按新名称下载文件。
- **组合与缩放。** 画布选区旁提供组合／取消组合入口，多选或组合后可拖动包围框四角等比缩放；单个未旋转图形保留原有自由宽高调整。一次拖动对应一次撤销，按 Escape 取消当前变换。
- **每次旋转 5°。** 点击包围框右上方的旋转按钮，图形顺时针旋转 5°。旋转内容可保存、重新打开和导出 SVG／PNG，文字、图片与绑定连线同步更新。
- **快速回到图形中心。** 点击右下角聚焦按钮或按 Home，有选区时定位选区中心，否则定位全部图形中心；保持当前缩放比例。输入框中的 Home 仍用于光标定位。
- **连线设置就近调整。** “新建连线”设置移到“快捷图形”的连线工具旁，路径和箭头设置用于后续新增连线。
- **MCP 与格式兼容。** 画布接口新增旋转、缩放和选择后聚焦；改进旋转图形的边界、连线绑定及 JSON／XML 导入导出，保留旧画布文件兼容性。

名称与保存规则见[文档名称说明](https://github.com/ecojust/open-office/blob/master/docs/document-names.md)，画布操作与快捷键见[画布说明](https://github.com/ecojust/open-office/blob/master/docs/workflow.md)。文档改名后，已开启的 MCP 会话会停止，需要在当前文档重新开启。

## 验证与安装包

功能提交已通过 1100 项自动测试、类型检查与前端生产构建。画布浏览器验收分阶段完成 27 项独立检查，覆盖组合、缩放、旋转、保存与导出、连线设置和聚焦；浏览器检查不代替系统 WebView 验收。

发布流程要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建与检查通过，并执行 Intel 安装包的 Rosetta GUI 验收及 ARM 安装包的 macOS 26 输入编辑验收。Intel 验收使用 Rosetta，不代表实体 Intel Mac 图形硬件验证。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
