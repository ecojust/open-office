# Open Office 0.24.3 · 日历胶囊与工时分配修复

本版修复日历胶囊的圆角缝隙，加大事件标题，并让数字编辑只调整后续事件的工时。

## 更新内容

1. **胶囊边缘连续贴合。** 外框统一裁剪内部事件填充，修复紧凑月历、详情弹窗及极窄首尾事件的圆角不一致问题。选中、悬停、键盘焦点和分隔线拖动仍可使用。
2. **事件标题更清晰。** 月历标题加大到 11–12px，详情弹窗标题加大到 14px；数字字号保持不变，长标题仍可省略显示，六行月历继续适应窗口高度。
3. **工时只向后分配。** 输入数字时不改变实际分配，点击「确定」后保留前面事件的份额，仅按原比例向后分配余量；后面事件原来都为 0 时平均分配。例如 20%／30%／50% 中把第二项改为 40%，结果为 20%／40%／40%。
4. **明确剩余工时约束。** 超出剩余额度时拒绝提交，最后一项保留余量，在数字编辑弹窗中只读；调整前面的事项即可改变它。保留精确小数、取消、无修改确认、单次撤销及保存重开。

## 使用与兼容

沿用现有 `.oocalendar` 文件格式和 MCP 接口，无需迁移。每天合计仍为 100%／设置的全天时长；分隔线拖动仍按百分比 10% 或工时 0.5 小时吸附。上述向后分配规则适用于数字编辑弹窗。

详细操作见[日历便笺使用说明](https://github.com/ecojust/open-office/blob/899813eea211ca2c0decaca6d4844878a54ba9d6/docs/calendar-notes.md)，代码变更见 [PR #16](https://github.com/ecojust/open-office/pull/16)。
