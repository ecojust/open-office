# Open Office 0.10.1 · macOS 编辑稳定性

针对 macOS 26 上编辑表格后窗口仍在、全部标签消失的问题，增加 WebKit 兼容处理。已复现的故障是网页进程退出并重新加载，导致内存中的工作台状态丢失。

## 变化

- 在支持公开接口的 macOS 26.4 及以上系统，创建网页前启用 WebKit 兼容模式；保留 WebKit 已启用的锁定或未知模式。旧版 macOS、Windows 和三个编辑器的 Rust 文档实现保持原有运行路径。
- 兼容模式会关闭整个网页进程的 JIT，且可能不提供共享内存。当前编辑器使用非共享 WASM 内存，不依赖 SharedArrayBuffer；检查仍要求隔离环境和完整的编辑、导出、重开结果。
- 最终 ARM 安装包增加 macOS 26 上三种文档及 PDF 的完整往返验证，与真实系统键鼠编辑检查一起作为发布条件。

## 验证范围与限制

自动化记录实际 macOS 小版本、网页启动次数、文档内容和标签身份。用户报告环境为 macOS 26.5；目前复现及候选验证环境为 macOS 26.6.2，不能视为已在 26.5 实机验证。具体安装包结果以本次构建记录为准。

兼容处理可能影响大型文档的速度；目前不能据此确定导致进程退出的具体 WebKit 断言。本版不会恢复此前崩溃中丢失的未保存内容。

应用仍为 Alpha，未配置商业代码签名或 macOS 开发者公证。格式兼容、放映及开源许可说明沿用 [0.10.0](0.10.0.md)。
