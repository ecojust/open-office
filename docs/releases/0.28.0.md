# Open Office 0.28.0 · 数据库表图排版

代码图表中的 ER 数据库表改为按内容自动计算宽度，长字段和说明保持单行。

## 更新内容

- **每张表独立适应内容。** 按实际字体和字号测量字段、注释与表头，长文本不再受原先固定最大表宽限制。
- **字段与注释分列。** 数据库字段默认居左，对应注释居右；不同字号保持在同一行对齐。
- **清晰的表头。** 表名置顶、默认加粗，`CUSTOMER["客户资料"]` 中的说明显示在表名下一行。
- **四类文字独立设置。** 在「图表风格」中分别设置表名、表注释、字段、字段注释的字号、颜色、粗体、斜体和对齐。控件支持中英文界面。
- **保存与输出一致。** 样式可撤销、重做，并随原生文件保存；预览、SVG、PNG、打印和独立画布使用同一排版。

## 验证与安装包

发布流程要求 Windows x64、macOS Apple 芯片与 macOS Intel 的构建及原生保存、重开检查通过，并执行 Intel 安装包的 Rosetta GUI 验收和 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
