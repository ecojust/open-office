# Open Office 0.24.4 · 日历事件交互样式修复

本版调整日历事件的删除按钮与选中效果，让胶囊边缘保持连续，选中标记显示在边框内部。

## 更新内容

- **删除叉号无背景。** 月历和详情弹窗中的事件删除按钮采用透明背景，悬停时叉号变红；保留点击区域、键盘焦点和拖动时隐藏按钮的行为。
- **修复胶囊选中效果。** 用内部底色高亮和底部标记替代矩形选中阴影，避免首尾、单个事件的选中线与胶囊圆角错位。统一外框裁剪与分隔线拖动保持不变。
- **普通事件描边内收。** 非工作事件的选中描边改为显示在边框内部，避免向外扩张。

本版不改变 `.oocalendar` 文件格式、工时分配规则及 MCP 接口，无需迁移已有日历。

## 验证与安装包

本地 Chromium 定向检查 11／11 通过，覆盖工时编辑、撤销及保存重开、Week／Work／全屏布局和分隔线拖动。34 个胶囊场景的 43,376 个内侧边缘像素检查未发现缝隙；另已查看首尾及单个事件选中后的实际截图。浏览器检查不代替系统 WebView 验收。

发布流程要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建与检查通过，并执行 Intel 安装包的 Rosetta GUI 验收及 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
