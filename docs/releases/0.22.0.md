# Open Office 0.22.0 · 排期工时预算与 MCP

本版为「计划排期」增加总工时、预算和完整 MCP 接口，月度工时改为胶囊进度，并修复排期标题遮挡全局菜单的问题。

## 更新内容

1. **月度工时胶囊。** 标签按百分比填充，继续采用 `26.10-40%` 格式、每行两个；工时为 0 的月份不显示。月份较多时可独立滚动，最小轨道高度和深色界面均保留完整标签。
2. **总工时与预算。** 人员下方显示各自总工时，项目标题旁显示项目合计。项目设置新增「工时单价（元 / 人天）」，悬停总工时即可查看人天、单价和总预算。全天计 1 天，半天计 0.5 天，扣除周末和假日；整体计划不重复计入。金额先按总人天计算，再四舍五入到分。
3. **PNG 同步工时显示。** 导出图片包含人员及项目总工时、按比例填充的月度胶囊，并隐藏零工时月份。保留完整日期和全部轨道，仍不显示事件数量；预算通过界面悬停查看，不写入图片。
4. **排期 MCP。** 桌面版打开排期后可启用当前文档的 MCP 服务，提供 11 个工具，覆盖项目、人员、事件增删改和复制、日历与周号、轨道高度、工时预算、视图缩放及选择、JSON 导入和 JSON／PNG 导出、假日更新、撤销与重做。批量编辑原子提交，出错全部回滚，与界面和保存状态同步；只读权限及文档会话隔离沿用现有规则。
5. **修复菜单遮挡。** 将编辑器内部层级限制在编辑区，排期标题和固定表头不再遮挡全局「新建」菜单或弹窗。

## 使用与兼容

- 工时单价为整个项目统一价格，支持最多两位小数；留空表示未设置，填写 0 表示零单价。单价随排期和 JSON 保存，并支持撤销、重做。
- 本版可以读取旧排期。旧版本会忽略并在再次保存时丢弃新增的单价字段，因此含预算的文件请使用 **0.22.0 或更新版本**编辑。文件格式版本仍为 1，原有日期、人员和事件规则保持兼容。
- MCP 使用现有本机 HTTP 服务与访问密钥，只作用于当前文档；切换文档后服务停止。假日刷新最多等待 8 秒，慢网络下返回正在后台更新；PNG 返回上限为 7 MiB，较大的图片可通过界面导出。保存及自动保存仍使用原有文件流程。
- 未增加运行时依赖。PNG 仍限制最大边 16384 像素、总像素 2400 万，超大排期等比缩小。

详细操作见[计划排期使用说明](https://github.com/ecojust/open-office/blob/master/docs/project-scheduling.md)和 [MCP 接口说明](https://github.com/ecojust/open-office/blob/master/docs/mcp.md)。

## 验证与安装包

已完成工时、预算、数据校验、历史及 MCP 权限的自动化测试和生产构建。真实 Chromium 验收覆盖 16 项工时、预算和层级检查，以及 11 项原有布局与导出检查；真实 Rust HTTP 到 Vue 界面的 MCP 验收覆盖全部 11 个工具、62 条操作记录、JSON／PNG 导出、保存重开和失效会话保护。

发布要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建及验证通过，并对 Intel 安装包执行 Rosetta GUI 验收、对 ARM 安装包执行 macOS 26 输入编辑验收。发行页提供三个安装包、对应源码和 `SHA256SUMS`。

Intel GUI 验收使用 Rosetta；应用仍处于 Alpha，未配置商业代码签名或 macOS 开发者公证。
