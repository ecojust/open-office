# Open Office 0.5.0 · 四个工作区编辑与兼容性更新

提供 Windows x64、Apple Silicon Mac 和 Intel Mac 安装包。文档与 PDF 在本机处理，安装包自带运行所需的编辑引擎、中文字体和 PDF 后端，无需用户另装 Python。

本版更新：

- 文字：普通列表与层级、重新编号、真实撤销重做；页眉页脚局部编辑保留页码和链接；加强嵌入附件的文件保留。
- 表格：混合格式提示、富文本单属性修改、常规数字格式重置、填充与选区统计；保护数组、STOP 验证和合并覆盖格中的内容；改进新表格窗口准备失败时的文档保护。
- 演示：受支持的 SmartArt 节点改字、局部文字及段落排版、表格行列布局、颜色变换、独立透明度、文字装饰与高亮，改善 PPTX 与矢量 PDF 导出。
- PDF：批注管理、简单表单填写、页面整理保留表单；正文替换保护交互对象，避免误改共享样式。
- 界面：窄窗工具栏保持控件正常宽度并支持单行横向滚动；短窗口保留原生编辑画布的最小高度，通过独立区域滚动，避免画布过度压缩导致冻结行丢失；帮助页版本与构建包版本一致。

源码阶段完成 680 项 Node、68 项 Python 核心回归，以及实际编辑、下载文件独立检查和部分参考软件打开验证。文字列表与表格格式的生产界面共 21 组操作、650 项独立文件检查通过；窗口跟进另外验证了指定宽度、DPR 1/2、键盘输入与实际导出。各阶段证据与范围见仓库 `docs/rea-compatibility-progress.md`、`docs/word-list-and-sheet-format.md` 和 `docs/office-viewport-validation.md`。

已知限制：

- 本版不宣称任意复杂文档无损兼容。完整对象动画、SmartArt 结构与布局编辑、复杂排版、部分新函数仍未完全支持；PDF 暂无 OCR 和证书签名编辑。
- Calc 输入数值并按 Enter 后，直接再次点击原单元格可能无法移动选区，宽窗也可复现；不需要额外聚焦或 Home 操作即可触发。保存文件内容正确，但该鼠标输入异常尚未解决，不能算作全流程通过。
- 首次打开表格时，原生工具栏与画布可能晚于模型完成显示；已发现画面位置与实际点击位置短暂不一致。该首次呈现问题仍在下一轮排查，不能把模型就绪等同于全部交互已验证。
- ODT 跨样式续编号在不同软件中仍有显示差异；部分 XLSX 类型、隐藏状态和新函数也有既有内核限制。
- 窄窗与高分屏浏览器检查不等同于全部触屏、输入法或原生 WebView 兼容性验证。文字与表格的原生高级菜单保留原有外观。

发布流程要求三种安装包全部通过构建和规定的真实应用自检。Windows x64 在 Windows Server 2022 验证，ARM Mac 在 macOS 15 验证；Intel 包原生编译后，将未修改的 DMG 转移至 ARM Mac，通过 Rosetta 运行 x64 应用及 PDF 进程，核对文件、架构与签名。该检查不等同于真实 Intel GPU 或全部系统版本测试，也不代表上述复杂专项已在每个原生平台全部复跑。

macOS 包采用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 包没有商业代码签名。首次运行请按系统提示处理。发布附件仅包含三种安装包、对应提交的源码 ZIP 和 `SHA256SUMS`；JSON 诊断报告保留在 Actions artifacts，不作为下载附件。
