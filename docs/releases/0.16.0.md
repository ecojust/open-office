# Open Office 0.16.0 · 行业演示模板与编辑体验改进

本次更新扩展演示模板库，缩短自动保存周期，并修复画笔叠加和笔记图片粘贴。

## 更新内容

1. **100 套演示模板。** 保留原有 10 套，新增医疗、教育、金融、制造、科技等 18 个行业、每行业 5 种用途的模板。每套包含封面、内容和结尾，文字与矢量图形可编辑。模板栏支持名称和多个关键词搜索，可同时筛选内置模板与自己的模板。
2. **10 秒自动保存。** 已选择本机保存位置的文档每 10 秒自动保存，旁边显示实际倒计时。输入法组合输入、编辑弹窗和未确认草稿仍会暂缓保存，完成后自动继续。
3. **画笔透明度叠加。** 修复自定义笔触在交叉、折返处出现透明缺口的问题，预览及 SVG、PNG 导出使用一致的叠加方式，并保留线宽、压感和笔刷效果。
4. **代码图表鼠标缩放。** 预览支持滚轮和捏合缩放，以鼠标位置为中心，范围为 40%–300%；源码区域正常滚动。新建代码图表默认使用中文时序图示例，已有文档保持原内容。
5. **笔记网格按需显示。** 开启网格吸附时，仅在拖动区域块期间显示网格；松手、取消或调整大小时隐藏，继续保留对齐参考线和吸附功能。
6. **恢复笔记图片粘贴。** 支持在空白画布或区域块中粘贴从系统文件管理器复制的多张 PNG／JPEG，完善 macOS 剪贴板文件读取与快捷键处理，同时保留截图、富文本和普通文字粘贴。
7. **画布矩形与绘制默认值。** 选中矩形后可在属性栏设置圆角，默认 0（直角）；连线默认使用直线，画布默认开启网格吸附，仍可手动切换。
8. **连续作画模式。** 锁图标移到画布工具栏最左，与选择、拖动互斥；开启后保留绘图工具，支持连续绘制，按住空格仍可临时平移。
9. **统一打印流程。** 文字、表格、演示与 PDF 打印导出的 PDF 页面；笔记打印已提交编辑的当前页，画布和代码图表打印完整画面。桌面版接入系统打印，准备失败会明确提示，未就绪的打印入口禁用。
10. **精简软件介绍。** 右上角信息弹窗用简短文字介绍七个子软件，底部提供“软件及交流群”二维码，并保留版本号与构建时间；打开时虚化背景，支持浅色与深色界面。移除工作台左下角的“格式支持与快捷键”入口，以及各新建卡片右上角的格式与英文标签。

## 验证与使用说明

本地自动测试、类型检查和浏览器回归覆盖画笔交叉像素、图表缩放、真实 10 秒自动保存、笔记拖动与图片粘贴、模板名称搜索及存储。浏览器测试不能代替安装包原生运行；发布流程要求 Windows x64、macOS ARM64、Intel 原包 Rosetta 和 macOS 26 原包编辑验收通过，具体结果见对应构建记录。

笔记单张图片上限为 4 MB，一次最多粘贴 16 张、合计不超过 16 MB，笔记文件仍受整体容量限制。macOS 系统文件粘贴的浏览器回归使用本机接口替身，不代表已覆盖真实 Finder 到 WebView 的交互。

打印桥已进行 macOS 与 Windows API 类型检查。浏览器回归使用系统打印接口替身，不能证明系统对话框或打印机实际工作；原生打印仍需分别验收。Windows PDF 打印保留独立预览，必要时可在预览工具栏再次点击打印。Linux 桌面打印暂未接入，会显示明确提示。

应用仍处于 Alpha。当前未配置商业代码签名或 macOS 开发者公证；发布附件包含 Windows 安装程序、两种架构的 macOS DMG、对应源码及 `SHA256SUMS`。
