# Open Office 0.15.0 · 画布、代码图表与自动保存倒计时

本次更新新增两个本地工作区，并改进自动保存反馈、演示操作、笔记布局和品牌图标。

## 更新内容

1. **画布。** 支持图形与连线、文字便笺、图片、六种画笔、分组对齐、图层、缩放和网格吸附，内置六套模板。保存为 `.owflow`，支持导入图形 XML、白板 JSON，以及导出 SVG、PNG 和兼容格式。
2. **代码图表。** 支持 22 类图表、46 个示例、10 种样式，源码与 SVG 预览联动，提供错误提示、源码定位和独立画布副本。支持 `.owflow`、`.mmd` 等格式及 SVG、PNG 导出。
3. **统一文件操作。** 新工作区接入工作台、新建菜单、多文档标签、全局保存、撤销、打印和主题。保存写回原文件；兼容格式导入后转换保存，图片导出保留当前文档的保存位置。删除和放弃未保存修改需要确认。
4. **自动保存倒计时。** 保留每 30 秒保存的周期，在开关旁显示实际倒计时、保存中、已保存、等待输入和失败重试状态。新文档提示先手动选择保存位置；输入法组合输入和未确认草稿不会被后台保存强行提交。
5. **演示操作调整。** 模板入口移至 PPT 操作栏“视图”右侧；内置模板和自定义模板继续可用。选中幻灯片缩略图后按回车复制当前页，正文编辑中的回车仍用于换行。
6. **笔记对齐。** 移动区域块时显示边缘和中心对齐参考线，并提供 10 像素网格吸附；按住 Alt／Option 临时绕过吸附。支持滚动和缩放后的正确定位。
7. **青牛图标。** 顶部品牌、浏览器图标和 Windows／macOS 应用图标使用指定的青牛图案。

## 验证与使用说明

本地单元测试及浏览器回归覆盖新工作区编辑、保存重开、跨标签草稿、删除确认、格式转换、SVG／PNG 导出与真实 30 秒自动保存调度。原生发布流程还要求 Windows x64、macOS ARM64、Intel 原包 Rosetta，以及 macOS 26 原包输入和完整编辑器验收通过；各平台结果与源码提交见对应构建记录。

应用仍处于 Alpha。画布与代码图表使用本地 TypeScript 模型和 SVG 渲染，四种办公文档编辑器继续使用 Rust/WASM。单份画布文档上限为 50 MB；兼容导入和复杂图表可能存在格式差异。当前未配置商业代码签名或 macOS 开发者公证；发布附件包含 Windows 安装程序、两种架构的 macOS DMG、对应源码及 `SHA256SUMS`。
