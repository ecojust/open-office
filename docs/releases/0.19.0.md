# Open Office 0.19.0 · 七应用 MCP 编辑与实时更新

MCP 从基础读写扩展到七个子软件的文档编辑功能。AI 客户端直接操作当前界面使用的文档模型，编辑结果即时显示，并进入正常的撤销、重做和保存流程。

## 更新内容

1. **文字文档。** 支持查找和选择文字、修改字符与段落格式、样式列表、表格、图片图形、页面布局、页眉页脚、批注修订等。可以先发现可用命令及参数，再执行编辑或查询结果。新增文档内复制、剪切、剪贴板历史、重复编辑、表格绘制和擦除；文档插入、样式复制及模板样式更新通过内嵌文档字节完成，保留当前文档身份和撤销记录。
2. **电子表格。** 开放批量写入、公式、单元格格式、行列与工作表操作、排序筛选、图表图片、数据透视表、批注及打印布局等命令，修改后更新当前工作表。
3. **演示文稿。** 支持页面、文字、形状、图片、表格、图表、主题母版、过渡动画和备注批注，并可查询、应用内置模板；编辑同步更新画面与缩略图。
4. **PDF。** 开放文字图像、字体导入、批注高亮、签名图章、表单及其动作和脚本内容、文档脚本内容、书签链接、页面管理、水印页眉等操作。素材通过内嵌数据传入，操作后的文档可正常导出。PDF 的 WASM 使用体积优化构建；命令目录拆分为小函数并共享静态定义，减少 WebKit 编译压力与每次调用的目录构造开销。
5. **笔记本、画布和代码图表。** 笔记本支持分区、页面、子页及区域内容与布局编辑；画布支持图形、连线、笔迹、图片、组合、层级、对齐和模板；代码图表支持源码、名称、风格与模板更新，并同步刷新预览。笔记本和画布的批量编辑会整体校验，失败时不留下部分修改。
6. **编辑权限更清楚。** 工作区显示“只读 / 允许编辑”，可直接进入设置。新配置默认允许编辑，升级保留已有权限；原先设为只读的用户，需要在 MCP 设置中开启编辑权限。
7. **文档会话保持独立。** 切换或关闭文档仍会停止 MCP 服务，并使未执行的请求失效。编辑不会改到其他标签页，保存和自动保存继续使用原有流程。

另修复旧版 macOS WebKit 后台优化可能引起的页面重启：四个编辑器的 WASM 构建使用等价的整数比较指令，避开已确认的系统优化器溢出问题。完整功能和原有发布验证要求保留，技术说明见 [WASM 兼容性](../wasm-webkit-compat.md)。

## 使用方式

在左下角设置 MCP，开启“允许编辑当前文档”，将配置复制到支持 HTTP MCP 的 AI 客户端。进入文档后点击 MCP，显示 Running 即可使用。完整工具、命令发现及参数说明见 [MCP 使用说明](../mcp.md)。

服务仅监听本机，需访问密钥认证。文档编辑接口不提供任意系统命令或读取其他文件的能力；需要素材的命令通过内嵌数据接收素材。依赖选区或对象的命令，应先定位对应内容；尚未结束的手动输入或弹窗应先完成。

## 验证与安装包

本地已完成七个实际编辑器的 153 次 HTTP 交互，覆盖编辑后的界面变化、撤销重做、导出、只读限制和切换文档停止服务。生产构建与自动化测试通过。发布流程另验证安装包内七应用的 MCP 编辑、实际文档和导出文件，并要求 Windows x64、macOS ARM64、Intel 原包 Rosetta 与 macOS 26 原包编辑检查通过后才公开安装包。

发布附件包含 Windows 安装程序、两种架构的 macOS DMG、对应源码和 `SHA256SUMS`。Intel 安装包在 Rosetta 环境验证，尚未覆盖实体 Intel Mac 图形硬件。应用仍处于 Alpha，未配置商业代码签名或 macOS 开发者公证。
