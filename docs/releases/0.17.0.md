# Open Office 0.17.0 · 全局导航与外观入口调整

调整桌面工作台布局，解决 Windows 原生标题栏与应用顶部重复显示 Logo 和名称的问题。

## 更新内容

1. **全局入口移到左下角。** 青牛 Logo、软件名称、版本与构建时间、主题切换和使用说明集中到侧栏底部。顶部保留新建、打开、保存、自动保存、导出、打印和撤销等文档操作。
2. **编辑时使用紧凑侧栏。** 打开文档后侧栏收窄，仍可随时切换浅色、深色、跟随系统主题，以及打开软件说明。返回工作台后恢复完整导航和正在编辑的文档列表。
3. **完善小窗口布局。** 左下入口固定显示，文档列表独立滚动；较窄窗口的工作台卡片隐藏辅助加号，为应用名称保留空间。
4. **保留统一的操作反馈。** 主题选择继续跨文档生效并记住设置；说明弹窗保留毛玻璃背景、软件及交流群二维码、键盘焦点约束和关闭后的焦点恢复。

## 验证与安装包

本地构建、类型检查和浏览器回归覆盖全局文件操作、主题持久化、编辑焦点、六种界面的深浅主题与窄屏，以及 900 × 640 窗口下的笔记编辑、说明弹窗和长文档列表滚动。原生安装包通过发布流程分别验证 Windows x64、macOS ARM64、Intel 原包 Rosetta 以及 macOS 26 原包编辑后发布，具体结果见对应构建记录。

应用仍处于 Alpha。当前未配置商业代码签名或 macOS 开发者公证；附件提供 Windows 安装程序、两种架构的 macOS DMG、对应源码与 `SHA256SUMS`。
