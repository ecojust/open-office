# Open Office 0.23.0 · 全屏编辑

八种工具统一支持「全屏编辑」，隐藏全局导航和设置，把更多窗口空间留给当前文档的操作区。

## 更新内容

1. **统一入口与退出。** 打开文档后点击右上角「全屏编辑」，收起侧栏、全局文件工具、文档标签、MCP 设置栏和底部状态栏。保留紧凑的文档名称、保存状态及「退出全屏」按钮，点击即可恢复完整界面。文字、表格、演示、PDF、笔记本、画布、代码图表和计划排期均可使用。
2. **排期主体更宽敞。** 同时收起项目名称、项目设置、人员管理及导入入口，保留人员／事件切换、视图与缩放、撤销／重做、事件编辑和导出。人员工时胶囊继续显示；事件操作栏保持固定高度，首次拖动未选中事件时不会被布局变化打断。
3. **其他工具保持编辑能力。** 保留各工具的文字排版、单元格、绘图、页面和笔记操作。PDF 收起图章署名设置；演示进入时收起模板侧栏，需要时仍可重新打开。
4. **保留当前工作。** 切换不重新创建编辑器，不丢失内容或撤销历史；保存快捷键、自动保存及已开启的 MCP 服务继续工作。切换文档或返回工作台时恢复完整界面。
5. **退出操作互不干扰。** Esc 优先交给当前编辑器，用于关闭弹窗、取消拖动或退出幻灯片放映；未被使用的 Esc 才退出主体全屏。打开编辑弹窗时先完成或取消弹窗，焦点保持在弹窗内。

## 使用与兼容

- 这是应用窗口内的主体全屏，与操作系统全屏及幻灯片放映独立。右上角的「退出全屏」始终保留，不依赖编辑器是否占用 Esc。
- 没有新增运行时依赖，也没有改变文件格式、排期数据结构或 MCP 协议。全屏状态只属于当前视图，不写入文档。
- 排期预算沿用 0.22.0 的兼容规则：含工时单价的文件请使用 0.22.0 或更新版本编辑；更早版本再次保存时会丢弃单价字段。

详细操作见[计划排期使用说明](https://github.com/ecojust/open-office/blob/master/docs/project-scheduling.md#全屏编辑)。

## 验证与安装包

功能改动已通过完整生产构建及 967 项自动化测试。真实 Chromium 验收共 21 项，覆盖八种工具的区域扩展、会话与历史保留、继续编辑和退出，以及排期首次拖动、四类手势的 Esc 取消、弹窗焦点、深色窄窗口和演示 F5／Esc。1440 × 1000 窗口下，共享编辑区由 1376 × 845 扩大到 1440 × 968，面积增加约 20%。

发布要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建及验证通过，并对 Intel 安装包执行 Rosetta GUI 验收、对 ARM 安装包执行 macOS 26 输入编辑验收。浏览器全屏编辑专项与这些安装版整体验收分别执行；发行页提供三个安装包、对应源码和 `SHA256SUMS`。

Intel GUI 验收使用 Rosetta；应用仍处于 Alpha，未配置商业代码签名或 macOS 开发者公证。
