# Open Office 0.20.0 · 项目计划排期与假日自动更新

新增独立的「计划排期」工具。为项目设置日期范围，添加人员名称、角色和颜色，按自然周 W1、W2…安排工作；排期与其他文档一样使用独立标签、本地文件和保存流程。

## 更新内容

1. **人员与全局两种视图。** 人员模式每人一条轨道，事件可以跨人员拖动；全局模式按开始日期混排全部人员的事件，保留负责人和颜色。整体计划始终固定在顶部，日期表头与左侧标签在滚动时保持可见。
2. **整天吸附与半高显示。** 左右拉伸后对齐整天，至少保留一天；拖动底边后高度吸附到 100% 或 50%。半高只改变显示高度，同一人员同一天仍不能放两个事件。冲突修改会被拒绝，原有事件保留，并支持撤销、重做。
3. **自动获取法定假日。** 默认隐藏周末和中国大陆法定假日。打开项目、调整日期范围或切回项目时检查相关年度数据，按 24 小时缓存策略更新，也可点击「更新假日」立即刷新。涉及十二月时同时检查次年公告，正确处理跨年安排。
4. **缓存与断网回退。** 主数据源失败时尝试备用源；空表、异常响应和网络失败不会覆盖最近有效数据。桌面缓存保存在应用数据目录，重启后仍可使用；另有 2025、2026 年内置假日兜底。手动添加或排除假日始终优先，更新不会改写事件日期或打断当前拖动。
5. **本地排期文件。** 使用 `.ooschedule` 保存项目日期、人员、事件和手动日历设置，支持保存重开、自动保存、最近文件及多标签编辑。排期 JSON 导入后另存为原生格式，保留源文件；无效导入不会替换当前排期。

假日数据由 `NateScarlet/holiday-cn` 按官方公告整理，GitHub 为主源，jsDelivr 为备用源。联网只请求年份，不上传项目名称、人员、事件或文档内容。尚未获取到有效年度安排时会显示提示；来源和 CDN 的更新可能滞后于官方公告。调休上班的周六、周日仍受周末显示开关控制，默认隐藏。

## 使用方式

从工作台或「新建」菜单打开「计划排期」，设置项目日期，再点击「管理人员」和「添加事件」。双击空白轨道可添加事件，双击事件可修改内容、负责人和日期。

详细操作与截图见[计划排期使用说明](https://github.com/ecojust/open-office/blob/master/docs/project-scheduling.md)，数据来源、缓存及日期规则见[排期日历说明](https://github.com/ecojust/open-office/blob/master/docs/schedule-calendar.md)。新工具复用现有工作台，没有新增运行时依赖；本版排期暂不提供打印或 MCP 编辑入口。

## 验证与安装包

本次功能已通过 894 项自动化回归、28 组真实浏览器检查、9 项原生文件／缓存／HTTP 测试，以及完整生产构建。浏览器检查覆盖跨轨道拖动、整天和半高吸附、冲突保护、保存重开、离线缓存、跨年公告及更新与拖动同时发生的情况。

发布流程针对 Windows x64、macOS Apple 芯片和 macOS Intel 构建安装包，并在各平台要求的原生验收完成后公开附件。安装包、对应源码和 `SHA256SUMS` 以发行页实际附件为准。Intel 包的发布验证使用 Rosetta，不等同于实体 Intel Mac 图形硬件验证；应用仍处于 Alpha，未配置商业代码签名或 macOS 开发者公证。
