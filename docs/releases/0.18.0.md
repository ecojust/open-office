# Open Office 0.18.0 · 本机 MCP 与文档协作

桌面版新增当前文档 MCP 服务。支持 HTTP MCP 的 AI 客户端可以连接本机 Open Office，读取正在打开的文档，并在获得编辑权限后修改实际内容。

## 更新内容

1. **集中配置与按文档启停。** 左下角新增 MCP 设置，可调整端口、读取访问密钥并复制客户端配置。打开文档后，在工作区点击 MCP 启动服务；只有启动成功才显示 Running。默认地址为 `http://127.0.0.1:19780/mcp`，服务每次需手动开启。
2. **默认只读，按需允许编辑。** 默认仅提供读取工具。勾选“允许编辑当前文档”并保存设置后，才提供编辑、撤销和重做工具。连接使用访问密钥认证，服务仅监听本机。
3. **七种文档接入实际编辑器。** 文字文档支持读取正文、插入文字；电子表格支持读取区域、写入单元格及公式；演示文稿支持读取幻灯片、新增标题和正文页；PDF 支持读取可提取文字和批注、添加文字框；笔记本支持读取内容、新增页面和文字区域；画布支持读取内容、新增图形和文字；代码图表支持读取、更新源码及预览。
4. **编辑与保存保持一致。** 工具操作更新实际文档和撤销历史，文档显示为未保存；保存及自动保存仍通过原有文件流程完成。新建文档需要先选择保存位置，工具不自行写入其他文件。
5. **当前文档独立会话。** 切换文档、返回工作台、关闭当前文档、保存 MCP 配置或退出应用都会停止服务，切回来需重新开启。服务停止后，尚未执行的请求失效；工具调用按顺序执行，并设有等待时限。
6. **延续简洁的全局布局。** 青牛 Logo、名称、版本与构建时间、主题和使用说明集中到左下角，顶部保留文档操作。编辑时侧栏收窄，小窗口下文档列表独立滚动。

## 连接与使用范围

连接步骤、各工具名称和参数约定见 [MCP 使用说明](../mcp.md)。协议支持 `initialize`、`ping`、`tools/list` 和 `tools/call`，通过 HTTP 返回 JSON；当前不提供 SSE 推送。此功能面向桌面版，浏览器版不能启动本机服务。

读取工具对文本和集合大小设有限制，不返回图片二进制内容；PDF 读取依赖文档中的可提取文字。提供的编辑工具是各子软件的常用操作，不等同于全部界面命令。本服务不提供任意脚本执行、系统命令或访问其他文件的工具。客户端配置包含访问密钥，请勿公开分享。

## 验证与安装包

本地已通过 818 项自动化测试、11 项 Rust HTTP 服务测试，以及覆盖七个实际编辑器的 52 次 HTTP/工具交互；验证了编辑、撤销重做、导出持久化、只读限制和切换文档停止服务。前端生产构建与 Windows 原生代码编译检查通过。安装包还须通过实际 MCP 通信、Windows x64、macOS ARM64、Intel 原包 Rosetta 和 macOS 26 原包编辑验收后发布，最终结果以对应构建记录为准。

应用仍处于 Alpha。当前未配置商业代码签名或 macOS 开发者公证；发布附件提供 Windows 安装程序、两种架构的 macOS DMG、对应源码和 `SHA256SUMS`。
