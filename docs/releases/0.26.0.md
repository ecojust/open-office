# Open Office 0.26.0 · 代码图表编辑与紧凑工作台

本版完善代码图表的编辑与预览操作，并压缩首页入口卡片，为最近打开的文件留出更多空间。

## 更新内容

- **滚轮滚动，Ctrl＋滚轮缩放。** 图表预览保留原生水平、垂直滚动；按住 Ctrl 滚动或触控板捏合时，以指针位置为中心缩放。标题栏仍可放大、缩小或恢复 100%。
- **源码与预览自由调整。** 拖动中间分隔条调整两侧宽度，窄窗口中可调整上下区域高度。支持方向键微调、Home／End 和双击恢复默认比例。
- **源码折叠与语法高亮。** 关键字、标签、数字、连线和注释使用不同颜色，适配浅色与深色主题。行号旁可折叠嵌套代码块，继续编辑后展开保留完整源码；定位错误时自动展开对应代码。
- **支持 # 注释。** 可使用独立一行的 `# 注释`，或在语句末尾添加 ` # 注释`；行内 `#` 两侧需留空格。颜色值、引号与节点标签中的 `#`、类图的 `#protected` 成员保留原义，注释不会改变错误行号或源码与图形的定位关系。
- **首页入口更紧凑，文件列表移到左侧。** 九种工具保留原有入口，以更小的横向卡片呈现；最近打开与正在编辑集中在左侧栏，方便查找与切换文件，较小窗口也可滚动浏览。

操作说明见[画布与代码图表](https://github.com/ecojust/open-office/blob/master/docs/workflow.md)。源码继续随文档完整保存，并支持撤销、重做、模板替换和 SVG／PNG／源码导出。

## 验证与安装包

发布流程要求 Windows x64、macOS Apple 芯片与 macOS Intel 的构建及原生保存、重开检查通过，并执行 Intel 安装包的 Rosetta GUI 验收和 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
