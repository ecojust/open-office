# Open Office 0.10.0 · Rust 演示文稿与旧内核清理

演示文稿改用本地 Rust/WASM 引擎，PPTX 解析、文档模型、编辑画布、排版及导出由该引擎实际处理。文字、表格和演示统一使用各自的 Rust 编辑器，旧兼容内核和早期实现已移除。

## 主要变化

- 支持新建演示、打开 PPTX／POTX／PPSX、编辑幻灯片和文档对象、保存 PPTX、导出 PDF。
- 演示工作区接入顶部全局文件操作、撤销重做及浅色／深色／系统主题；操作栏使用 245 枚自绘 SVG 图标，正常界面不显示上游品牌。
- 各标签使用独立文稿会话；导入失败保留当前文稿，首次保存导入文稿生成副本，旧保存回执不会清除之后编辑的未保存状态。
- 移除 LibreOffice／ZetaOffice／Qt WASM 运行时、UNO 桥接、旧运行时下载与补丁、早期 TypeScript 编辑器及旧 Rust Word 内核和原生 IPC。构建新增检查，防止旧内核再次混入安装包。
- 字体资源迁移至公共目录，并保留原始字体许可、上游版权、依赖清单与对应源码说明。

## 验证与安装包

本地生产构建、258 项 Node 测试、83 项 PDF 后端测试、21 项原生文件与报告测试、5 项 PPT Rust 宿主回归测试通过。Word／Sheet／PPT 真实 WASM 浏览器验收、全局工具栏与主题验收通过；实际导出的 PPTX 和 PDF 经独立解析核对。PPT 资产归属、模块分层及源码／产物摘要检查通过。

上述浏览器及原生文件测试不等于安装包 WebView 验收。发布流程会重新构建 Windows x64、macOS ARM64 和 macOS Intel 安装包，并验证真实 WebView 中的三个编辑器与 PDF；全部通过后才公开安装包。Intel 包在 ARM Mac 上通过 Rosetta 验证，不等于真实 Intel 显卡测试。实际逐平台结果、源码提交及构建记录附于 GitHub 发行说明。

## 已知限制

- 旧 DOC、RTF、ODT、XLS、ODS、PPT、ODP 不再提供兼容内核，需先转换成当前支持的格式。
- 演示可插入、保存音视频，当前放映的 Web 音频输出尚未接通。部分高级文件选择入口暂时禁用并显示原因，具体范围见[集成说明](../deckcraft-integration.md)。
- 已收到 macOS 上编辑操作可能导致工作台全部标签消失的报告，正在复现和定位，本版不宣称已修复此问题。
- 当前仍为 Alpha；复杂动画、SmartArt、母版、特殊字体及跨应用排版可能存在差异。自动化检查不代替物理输入法、系统剪贴板或打印机验收。

安装包未配置商业代码签名，macOS 使用本地签名、尚未开发者公证。发布附件包含安装包、精确提交的源码与 `SHA256SUMS`。

## 开源来源

文字、表格、演示分别基于固定版本的 WordCraft、GridCraft、DeckCraft Rust 开源引擎，Open Office 提供本地宿主适配、统一文件生命周期、全局主题及原创 SVG 图标。PDF 保留 PDF.js 与 PyMuPDF／MuPDF。来源及许可证见[第三方声明](../../THIRD_PARTY_NOTICES.md)和[分发许可](../../DISTRIBUTION_LICENSE.md)。
