# Open Office 0.21.0 · 排期交互、月度工时与完整导出

本版完善「计划排期」：左侧人员下方直接显示每月工时占比，周号可按年或按项目计算，支持 Ctrl 拖动复制、边缘直接拉伸、上午／下午安排及完整数据和图片导出。

## 更新内容

1. **人员月度工时小列表。** 在人员名称和角色下方逐月显示百分比，悬停查看已排／可排天数，月份较多时可在列表内滚动。以当月项目范围内工作日为分母，全天计 1 天、半天计 0.5 天，跨月分别统计；周末及假日不计，整体计划不重复计入。事件修改、复制和撤销后实时更新，无可排工作日时显示「—」。
2. **按年／按项目两种周号。** 在「视图 → 周号」切换并随文件保存。默认采用全年 ISO 周历，周一开周，跨年显示所属年份；按项目从开始日期所在周记 W1，跨年继续递增。隐藏整周不重新编号，PNG 使用相同周号模式。
3. **直接拉伸与 Ctrl 拖动复制。** 无需先选中事件，鼠标移到实际边框即可调整日期或高度；普通拖动移动，按住 Ctrl 拖动主体复制。副本保留内容和高度，原事件不变，复制可一次撤销；日期冲突时整次拒绝。
4. **上午／下午与轨道刻度。** 半高事件可拖到轨道上半部或下半部，表示上午或下午，也可通过事件表单设置。左右拉伸仍按整天吸附，事件高度吸附到 100% 或 50%；轨道本身按 28px 刻度调整，范围 84–336px，随文件保存。半天标记不增加容量，同一人员同一天仍只允许一个事件。
5. **紧凑工具栏与时间轴缩放。** 人员／全局切换集中在顶部，周末、假日和列宽设置收进「视图」；假日更新只保留一条简短状态。Ctrl＋滚轮以鼠标位置为中心缩放时间轴，各标签独立；矮窗口避免固定整体轨道遮住人员。
6. **JSON 数据与整张 PNG。** 导入排期文件或 JSON 时在新标签打开；JSON 导出保留项目、人员、事件、周号和轨道设置。PNG 包含全部日期及轨道，包括滚动区域之外的内容，大表按尺寸上限等比缩小。月度工时是交互侧栏信息，PNG 继续输出排期时间轴。
7. **精简 Info 窗口。** 移除二维码、扫码文案和提取码，保留八种工具介绍、版本号及构建信息。

## 使用与兼容

操作说明和截图见[计划排期使用说明](https://github.com/ecojust/open-office/blob/master/docs/project-scheduling.md)，日历规则和格式见[排期日历说明](https://github.com/ecojust/open-office/blob/master/docs/schedule-calendar.md)。月度工时按工作日计算，显示周末或假日、缩放及切换周号不会改变统计结果；未知年份沿用当前已取得的日历数据，界面显示假日更新状态。

0.21.0 可以读取旧排期。包含下午事件（`slot: 1`）的新文件需要本版或后续支持时段的版本；0.20.0 会拒绝打开。旧版重新保存文件可能丢失新增的轨道高度及周号设置。无新增运行时依赖，排期仍保存在本地。

## 验证与安装包

942 项自动化测试和完整生产构建通过；本轮新增 9 项月度统计浏览器验收，并复验原排期 17 项及布局导出 11 项。该版本功能累计完成 80 项 Chromium 排期检查，覆盖拖动、复制、半天时段、跨年周号、缩放、文件往返、PNG、假日更新及月度列表。100 人、37 个月和 2000 个事件的工时结果另与独立逐日计算对照。Info 的浅色／深色显示、关闭和焦点恢复通过验证。

发布流程针对 Windows x64、macOS Apple 芯片和 macOS Intel 构建，并要求各平台原生检查、Intel 包的 Rosetta GUI 验收及 ARM 包的 macOS 26 输入编辑验收通过。发行页提供三个安装包、对应源码和 `SHA256SUMS`。Intel 验收使用 Rosetta；应用仍处于 Alpha，未配置商业代码签名或 macOS 开发者公证。
