# Open Office 0.24.0 · 日历便笺与工时分配

本版新增第九款工具「日历便笺」，将 CalendarNote 的月历记录体验接入 Open Office，并增加同日工时胶囊、历史事项复用和完整的日历 MCP 接口。

## 更新内容

1. **日历融入统一工作台。** 首页以 3 × 3 展示九种工具。日历本接入打开、保存、另存为、自动保存、多标签、撤销重做、打印与全屏编辑，所有月份一起保存在本地 `.oocalendar` 文件中。
2. **记录事项时减少弹窗打扰。** 单击日期只选中，通过「日期详情」按钮或右键菜单查看农历和黄历。右键可添加自定义事项、年假或病假；支持编辑、搜索、拖动改日期及 Ctrl／⌘ 拖动复制。农历和节气在本地计算，中国大陆法定假日复用年度数据获取与缓存。
3. **复用跨月历史事项。** 添加或编辑时，可以搜索以前使用过的名称，带入标题、颜色和是否需要上班；正文保留当前输入。历史随日历本保存，删除事项或清除某个月仍保留历史分类。
4. **按胶囊分配每天工时。** 默认每天 7 小时，同一天的工作事项组成一个胶囊。首项占 100%，增删、复制、跨日移动或改变工作属性后，受影响日期重新均分。拖动相邻分隔线可手动分配，百分比显示按 10 个百分点吸附，工时显示按 0.5 小时吸附；也支持方向键和 Home／End，Esc 可取消拖动。调整到 0% 仍保留事项的编辑入口。
5. **按实际分配统计。** 日历本设置可将每天工作时长调整为 0.5～24 小时，步长为 0.5 小时，原有分配比例保持不变。月度汇总显示各类事项实际折合天数、小时数和占比，打印包含相应工时信息。年假、病假等非工作事项独立显示，不占工作时长。
6. **开放日历 MCP。** 新增 `calendar_read`、`calendar_edit`、`calendar_set_view`、`calendar_export`，支持查询分页、历史事项、实际工时、日历本设置、批量事项编辑、完整份额分配和相邻边界调整。批量编辑整体校验、整体提交，可一次撤销，沿用当前文档权限与服务生命周期。

## 使用与兼容

- 从工作台选择「日历便笺」，右键日期添加事项。顶部「显示」可切换「百分比／工时」，日期格中的「调整」可打开较大的工时胶囊和完整事项清单。
- `.oocalendar` 使用 `open-office-calendar` 格式标记和版本 1，也可导入同样格式的完整 JSON。先前开发版中缺少工时设置的版本 1 文件仍可读取，默认每天 7 小时、百分比显示，未记录比例的同日工作事项按平均分配处理。原 CalendarNote 的 SQLite 数据库不属于此导入格式。
- 文件保存每天工时、显示方式、事项分配和历史。修改名称、正文、颜色或每天时长不会重置手动比例；事项数量、所属日期或工作属性变化时，相关日期重新均分。一个有工作事项的日期合计为 1 天，月度百分比以这些日期的总天数为分母。
- 日历 MCP 使用已有本机服务和权限。工时设置与分配属于文档编辑，需要允许编辑；切换视图可在只读权限下使用。JSON 导出不写入文件或标记已保存，保存仍通过现有文件操作完成。
- 日历便笺参考并适配 [CalendarNote](https://github.com/ecojust/CalendarNote)，保留原作者 MIT 许可与出处；农历计算使用 `lunar-typescript@1.8.6`。来源、许可与本地修改见[集成说明](https://github.com/ecojust/open-office/blob/2c83473dc52f7c56f30ce1e9b330fe624d30c274/public/legal/calendarnote/OPEN-OFFICE-INTEGRATION.md)。

详细操作见[日历便笺使用说明](https://github.com/ecojust/open-office/blob/2c83473dc52f7c56f30ce1e9b330fe624d30c274/docs/calendar-notes.md)，接口参数见[MCP 使用说明](https://github.com/ecojust/open-office/blob/2c83473dc52f7c56f30ce1e9b330fe624d30c274/docs/mcp.md#日历便笺接口)。

## 验证与安装包

本地已通过 1036 项 Node 自动化测试和完整生产构建。真实 Chromium 日历验收通过 15 组场景，并完成 Home／End 分隔线端点修复的针对性检查；覆盖事项与历史复用、移动复制、工时分配和显示切换、撤销重做、文件保存重开、多标签、全屏及深色窄窗口界面。

发布流程要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建与检查通过，并执行对应的原生安装包验收。本地验证范围限于上述测试与构建；逐平台结果和可下载安装包以本次 Actions 记录及发行页为准。发行材料应包括三个平台安装包、对应源码和 `SHA256SUMS`。

Intel GUI 验收使用 Rosetta；应用仍处于 Alpha，未配置商业代码签名或 macOS 开发者公证。
