# Open Office 0.9.0 · 电子表格与统一工作台

默认电子表格工作区更换为本地 Rust/WASM 编辑器，支持 XLSX、CSV、TSV 的打开、编辑与保存。文字和表格共用顶部文件工具栏与主题设置，功能区采用自行绘制的 SVG 图标。

## 主要变化

- 电子表格接入 Rust 工作簿模型、公式计算、功能区、公式栏、格式、工作表及图表等编辑入口。ODS、旧 XLS 保留兼容编辑器。
- 新建、打开、保存、另存为、导出 PDF、打印及撤销重做集中到顶部，操作当前文档；主页禁用依赖文档的操作。
- 浅色、深色与跟随系统改为全局太阳／月亮／显示器图标。选择自动记忆，并同步已有及新建的文字与表格会话；切换主题保留草稿及撤销历史。
- 顶部、文字与表格功能区使用原创 SVG 图标，统一圆角线条、间距与主题配色，适配浅深背景。
- 保留独立标签会话、未保存关闭确认、失败导入保护、导入文件首次另存副本与过期保存回执保护。保存前提交正在编辑的表格内容。
- 表格支持中文 PDF 导出；CSV／TSV 导出活动工作表的显示值，不包含公式、格式及其他工作表。

## 验证与安装包

发布前的生产构建、图标覆盖与两套引擎源码／产物摘要检查通过。0.9.0 全量回归通过 995 项 Node 测试和 83 项 PDF 后端测试。全局工具栏、主题及图标专项另有 5 组真实 Chromium 编辑、主题切换、保存与重开验收；实际导出的 DOCX／XLSX 经独立读取核对，浏览器报告没有页面或控制台错误。

表格引擎替换阶段的 9 组浏览器验收与 6 项自检逻辑复用检查属于此前快照，具体范围见[集成记录](../gridcraft-integration.md)。本版原生发布流程重新构建引擎与安装包，并验证真实 WebView 中的文字、表格、演示与 PDF 操作。Windows x64、macOS ARM64 与 macOS Intel 全部通过必要自检后才公开安装包；实际源码提交、逐平台结果与构建链接附在 GitHub 发布说明中。

Intel 安装包在 ARM Mac 上使用 Rosetta 验证，不等同于真实 Intel 显卡测试。自动化输入检查不代替物理输入法、系统剪贴板或物理打印机验收。当前为 Alpha 测试版，复杂文档、未建模工作簿对象与跨应用保真仍需核对；详见[文字](../wordcraft-integration.md)及[表格](../gridcraft-integration.md)集成说明。

安装包未配置商业代码签名，macOS 使用本地签名、尚未开发者公证。发布附件提供安装包、对应源码与 `SHA256SUMS`。
