# Open Office 0.27.0 · 中英文界面

本版为 Open Office 增加中英文切换。语言按钮位于左侧栏的皮肤切换旁，首页与编辑页均可使用，选择会保存在本机，下次启动自动恢复。

## 更新内容

- **统一切换九种工具。** 工作台、文件操作、设置、帮助，以及笔记本、画布、代码图表、计划排期、日历便笺、文字文档、电子表格、演示文稿和 PDF 的界面使用同一语言设置。
- **即时切换并保留编辑现场。** 无需重新打开文件；文档内容、文件名、选中位置、未提交输入和撤销记录保持不变。
- **更完整的英文界面。** 工具提示、无障碍标签、对话框、状态提示、模板库及日期显示随语言切换。系统文件对话框采用所选语言的文件类型名称，其系统按钮继续使用操作系统语言。
- **保留内容原貌。** 内置模板名称与说明可切换语言，自定义模板名称、文档正文、图表源码、日历农历及节假日名称保留原值。切换界面语言不改变公式语法或文档校对语言。

## 验证与安装包

发布流程要求 Windows x64、macOS Apple 芯片与 macOS Intel 的构建及原生保存、重开检查通过，并执行 Intel 安装包的 Rosetta GUI 验收和 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
