# Open Office 0.13.0 · 自由布局笔记与编辑体验优化

本次更新包含笔记本、演示模板、PDF 署名、Word 弹窗、自动保存和工作台布局的改进。安装包仅在对应提交通过完整构建及原生验收后发布，下载以[发布页](https://github.com/ecojust/open-office/releases)为准。

## 更新内容

1. **笔记本支持子页面与自由排版。** 在页面上右键可添加子页面；文字和图片放在独立区域，可移动位置、调整大小，图片保持比例缩放。搜索结果跳转后持续高亮匹配内容，清空关键词后取消高亮。旧版笔记文件可读取，并在保存时转换为新的结构化格式。
2. **新建演示自动生成三页。** 封面使用淡色渐变底图，带可编辑主标题、副标题和署名；内容页包含原创矩形矢量图案与标题；结尾使用醒目底图和居中的 `open office` 艺术字。已有演示文件按原内容打开。
3. **PDF 图章可设置署名。** 不再默认写入 Guest，署名在本机记住；中文署名通过字体轮廓绘制，并保留可读取的逻辑文字。未填写署名时省略署名行。可视图章和签名不等同于数字证书签署。
4. **Word 弹窗统一外观。** 字体、明暗配色、标题栏、圆角、输入框和底部按钮与主体界面协调；长内容可滚动，窄窗口中的操作按钮可换行。
5. **修复自动保存延迟。** 正常间隔仍为 30 秒；到期遇到输入、弹窗或未确认草稿时，每 1.2 秒重新检查，完成编辑后及时继续。顶部明确显示等待、保存中、已自动保存或待重试；只有实际写入及对应版本回执成功才清除未保存状态。新文档仍须先手动选择保存位置。
6. **工作台列表独立滚动。** 最近文件较多时仅列表内部滚动，标题、搜索和页脚保持固定；移除单独的“最近打开”菜单。小窗口采用紧凑的新建卡片，搜索变化时回到列表顶部，左侧正在编辑的列表保持独立滚动。

## 验证与使用说明

发布前检查包括 TypeScript 和 Node 回归、四套 Rust/WASM 引擎构建、笔记文件读写、三页模板及图章文字回归，以及命名、图标和引擎边界检查。浏览器检查覆盖笔记本编辑、自动保存等待与恢复、PDF 署名和工作台滚动；模拟文件接口的浏览器检查不能代替原生磁盘写入验收。

发布流程要求 Windows x64、macOS ARM64、Intel 应用和 macOS 26 验收通过。原生检查覆盖四套编辑器、笔记本保存重开和正常 30 秒计时下的自动保存，核对磁盘文件、精确版本回执和独立解析结果。Intel 安装包通过 Rosetta 运行验收，不等同于物理 Intel GPU 检查；系统输入法与文件选择器的全部行为也不由这些检查保证。

应用仍处于 Alpha，复杂文档请核对保存后的文字与版式。`.oonote` 为本应用的本地笔记格式。当前未配置商业代码签名或 macOS 开发者公证；发布附件提供 Windows 安装程序、两个架构的 macOS DMG、对应源码与 `SHA256SUMS`。
