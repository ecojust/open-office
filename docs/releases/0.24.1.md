# Open Office 0.24.1 · 日历拖动与显示修复

本版修复日历胶囊事件在 Windows 桌面端的拖动拦截问题，让全月工作汇总跟随显示单位，并统一工作台下拉框与输入框的高度。

## 更新内容

1. **修复日历事件移动与复制。** 主窗口关闭会拦截 HTML5 拖动事件的 Tauri 原生文件拖放处理器。可从胶囊文字处拖到另一日期，也可按住 Ctrl（macOS 使用 ⌘）拖动复制；落在已有胶囊或日期格的「调整」按钮区域时也能识别目标。文件选择对话框保持可用。
2. **修正拖动提示。** 拖动时隐藏源事件的删除叉，目标日期显示移动或复制提示；移出目标、取消或完成拖动后清理高亮。扩大后的「调整」弹窗保留分隔线工时调整，事件本体不再显示无效的拖动操作。
3. **月度汇总使用所选单位。** 设置为「工时」时显示小时，设置为「百分比」时显示折合天数，整月占比仍保留。汇总标签、悬停提示和打印使用相同单位；切换单位不会修改事项或工时分配。
4. **统一工作台下拉框高度。** 紧凑下拉框统一为 32px，日历与排期弹窗中的下拉框、单行输入框统一为 36px，减少垂直内边距挤压文字的问题。多行正文和颜色选择器保留各自尺寸。

## 使用与兼容

沿用 0.24.0 的文件格式和 MCP 接口，现有日历本可直接打开，无需迁移。拖动修复需要安装本版桌面客户端后生效。

详细操作见[日历便笺使用说明](https://github.com/ecojust/open-office/blob/5f5760df6c51ac8aeb6084d56bb262b34d5d7554/docs/calendar-notes.md)，代码变更见 [PR #11](https://github.com/ecojust/open-office/pull/11)。

## 验证与安装包

本地生产构建通过。Chromium 日历验收通过 26 组场景，覆盖实际鼠标移动、Ctrl／⌘ 复制、取消拖动、分隔线调整、保存重开、汇总单位和打印。下拉框在浅色 1440px、深色 1000px 窗口下分别检查了 9 个界面、20 个实例，覆盖全部 16 处 Vue 原生下拉框模板，文字未裁切且配对输入框等高。四个 Rust/WASM 编辑器的下拉框高度策略另做了源码检查，本版未修改它们。

Node 全套检查首次通过 1040／1042 项；其余两项因本地执行路径未包含 Cargo 而未能启动对应的 Rust 检查，补齐已安装工具链的路径后，定向复测 2／2 通过。上述浏览器证据不包含 Windows／macOS 系统拖动光标、拖动快照或原生 OLE 拖放实测。

发布流程要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建与检查通过，并执行 Intel 安装包的 Rosetta GUI 验收及 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页将提供三个安装包、对应源码和 `SHA256SUMS`。
