# Open Office 0.24.2 · 日历工时编辑与布局优化

本版支持直接编辑日历工时数字，让六行月历自动适应工作区高度，并调整应用入口顺序。

## 更新内容

1. **双击数字修改工时。** 双击胶囊中的百分比或小时数字即可打开编辑弹窗，支持输入小数，也可聚焦数字后按 Enter 或空格打开。确认后，其他事项按原比例分配剩余工时；其他事项原来都为 0 时平均分配。当天合计保持 100%／设定的全天时长，仅有一项工作时固定占满全天。取消或未修改直接确认不会改变分配，确认后的修改可一次撤销。
2. **月历高度自动适配。** Week、Work 和全屏编辑下，六行日期按可用高度自动等分，月历内不出现滚动条。窗口较小时使用紧凑预览，点击日期顶部的数量与「调整」可查看全部事项；从详情进入数字编辑后，确认或取消会返回原详情。
3. **完整月度汇总独立查看。** 顶部汇总保持一行，点击「全部 N 项」查看完整列表，避免事项多时挤占月历空间。
4. **调整应用入口顺序。** 首页、新建菜单和使用说明将 Word、表格、PPT、PDF 放到最后，四者保持原顺序。笔记本、画布、代码图表、计划排期、日历便笺排列在前。

## 使用与兼容

沿用 0.24.0／0.24.1 的文件格式与 MCP 接口，现有日历本可直接打开，无需迁移。直接输入数字不受分隔线的拖动刻度限制；拖动仍按百分比 10% 或工时 0.5 小时吸附。

详细操作见[日历便笺使用说明](https://github.com/ecojust/open-office/blob/7b3803f62f4c8232e248c60cc23ecf61d5ba827b/docs/calendar-notes.md)，功能变更见 [PR #13](https://github.com/ecojust/open-office/pull/13) 和 [PR #14](https://github.com/ecojust/open-office/pull/14)。

## 验证与安装包

日历改动通过 1049 项自动化测试、34 组 Chromium 回归及生产构建。浏览器回归覆盖数字编辑、拖动与复制、撤销、保存重开，以及 10 个 Week／Work、不同窗口尺寸和全屏布局场景；应用排序另通过类型检查及浏览器核对。上述浏览器检查不代替安装包的系统 WebView 验证。

发布流程要求 Windows x64、macOS Apple 芯片和 macOS Intel 的构建与检查通过，并执行 Intel 安装包的 Rosetta GUI 验收及 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
