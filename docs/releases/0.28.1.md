# Open Office 0.28.1 · ER 图遵循源码样式

撤销 ER 表名、表注释、字段和字段注释的独立文字设置，保持原有默认外观。需要修改样式时，可在源码中使用 Mermaid 已有的整表样式语法。

## 更新内容

- 移除四类文字的独立设置面板及文件配置；已有文件仍可打开，源码与其他文档内容保留。
- 支持 ER 实体的 `style`、`classDef`、`class` 与 `:::`，可设置整表颜色、边框、字号、粗体和斜体等已实现属性。未实现的属性会提示具体行号。
- 未写样式时，保留按文字自动计算表宽、字段单行居左、注释居右、表名置顶加粗及表注释放在表名下方的布局。
- 源码中明确指定的颜色优先于图表主题；预览、图片导出、打印和独立画布使用一致样式，`.mmd` 保留样式源码。
- 保留十种图表风格、预览拖动、普通滚轮滚动、Ctrl + 滚轮缩放、点击表格定位及展开源码。

语法示例与范围见[代码图表说明](https://github.com/ecojust/open-office/blob/master/docs/workflow.md)，标准依据为 [Mermaid ER 样式语法](https://mermaid.js.org/syntax/entityRelationshipDiagram.html#styling-a-node)。

## 验证与安装包

发布流程要求 Windows x64、macOS Apple 芯片与 macOS Intel 的构建及原生保存、重开检查通过，并执行 Intel 安装包的 Rosetta GUI 验收和 ARM 安装包的 macOS 26 输入编辑验收。逐平台结果以本次 Actions 记录为准；发行页提供三个安装包、对应源码和 `SHA256SUMS`。
