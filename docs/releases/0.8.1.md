# Open Office 0.8.1 · 文字编辑体验更新

文字工作区集中展示文档编辑工具，新建、打开、保存、另存为、导出 PDF 与打印统一使用 Open Office 外壳。日常界面不再显示上游编辑器品牌，来源和许可声明继续保留。

## 主要变化

- 移除内层标题栏、文件页、重复文件按钮与相关入口，保留文字、段落、表格、图片等编辑功能。保存状态统一显示在外壳。
- 修复功能搜索框的输入归属，搜索时不会把文字写入正文。
- 统一正文区域的 `Ctrl / ⌘ + Shift + S` 与 `F12` 另存为流程；外壳按钮获得焦点时，新建、打开、保存与打印快捷键仍可使用。
- 修复关闭当前标签后恢复原文稿的画布挂载竞态。旧标签卸载不会取消新标签的挂载，文稿内容、撤销历史与未保存状态继续保留。
- 保留导入 DOCX 首次保存副本、无效打开保留当前文稿、取消关闭不丢修改，以及 PDF 导出和打印不清除正文未保存状态的保护。

## 验证与安装包

本地生产构建与以下三套真实 Chromium 验收已通过，检查实际画布事件和导出文件，运行前后的产品源码摘要一致：

| 验收 | 通过数量 | 范围 |
| --- | --- | --- |
| 编辑区与外壳专项 | 4 组 | 编辑入口、文件快捷键与保存状态、多标签关闭恢复、PDF 导出与打印调用 |
| 完整文字回归 | 9 组 | 中文与 emoji 输入、输入法提交、格式、剪贴板、保存重开、失败打开及复杂 DOCX/PDF 独立检查 |
| 安装包自检逻辑的浏览器复用检查 | 6 项 | 本地 WASM 与画布、合成输入、格式、导出与保存回执、拒绝过期保存和无效打开、默认入口重开 |

上述结果证明浏览器集成；不代表原生 WebView、物理系统输入法或原生文件对话框已经通过本轮验收。打印检查覆盖真实 PDF 生成与打印调用，不包含物理打印机输出。

本轮构建 Windows x64、macOS ARM64 与 macOS Intel 安装包，全部通过必要自检后公开测试版。具体产物、源码提交及逐平台结果以 [Actions 构建记录](https://github.com/ecojust/open-office/actions/workflows/desktop-release.yml) 和 [发布页](https://github.com/ecojust/open-office/releases) 为准。Intel 包在 ARM Mac 上通过 Rosetta 验证，不等同于真实 Intel 显卡测试。[0.8.0 已公开发布](https://github.com/ecojust/open-office/releases/tag/desktop-v0.8.0-38691848013)。

默认文字引擎继续基于固定版本的 [WordCraft](https://github.com/storytold/wordcraft) 开源源码，仍处于 Alpha 阶段；复杂版式、特殊字体和跨应用文件保真范围见[集成说明](../wordcraft-integration.md)。本版不改变各组件的许可，原始来源、WordCraft／craft-ui 及字体许可随应用保留，见[第三方许可清单](../../THIRD_PARTY_NOTICES.md)与[集成分发许可](../../DISTRIBUTION_LICENSE.md)。
