# Open Office 0.6.2 · 自动文字颜色兼容

轻量文字编辑器现在支持 DOCX 自动前景色。之前因 `w:color w:val="auto"` 无法打开的受支持正文文档，现在可以编辑和保存，自动颜色与固定黑色分别保留。没有明确颜色的 DOCX 按样式继承，无上层颜色时使用自动颜色。

文字颜色菜单新增“自动”和“自定义”，支持混合选区、取消草稿及撤销重做。自动颜色参照受测 LibreOffice，根据文字底纹显示黑色或白色；高亮不参与判断。改变底纹后会重新计算显示颜色，保存 DOCX 时仍保留自动设置。复制到外部的 HTML 使用当前实际 RGB。

段落样式、字符样式、直接格式及独立段落标记分别保留。命名字符样式的颜色即使与当前段落相同，也能在 Enter 后继续生效；纯段落继承则随下一段样式改变。原有行距、下划线、背景色及 Rust 文档包处理继续提供。

兼容依据为固定 LibreOfficeDev 版本的 13 份完整原件、51 份未经修改的原生输出，含七个实际键盘编辑控制。独立 ZIP/XML、ODT、PDF 及文件校验共 548 项通过。专项与既有回归检查记录见 `docs/independent-word.md`，语料和可复现检查器随源码提供。

发布流程要求 Windows x64、macOS ARM64 和 macOS Intel 安装包构建成功并通过规定的实际应用自检。Windows 与 ARM Mac 直接运行；未修改的 Intel DMG 转移到 ARM Mac 后通过 Rosetta 检查。自检包含实际 Rust IPC、文档编辑、保存重开及 PDF 独立回读，详细结果见本次 Actions 记录。

轻量文字编辑器仍为预览，支持已实现的 DOCX 正文子集，尚无复杂分页、表格和图片。本次未增加主题前景色、透明色或页面／框架背景支持；兼容对照限于受测 LibreOffice 版本，未验证 Microsoft Word。既有安装包自检不代表全部新增颜色场景已在各平台 WebView 逐项验证。

完整文字、表格和演示工作区继续使用现有办公引擎，并非纯 Rust 实现。既有表格首次画面及工具栏交互、复杂演示编辑、PDF OCR 和证书签名限制继续适用。Intel 的 Rosetta 检查不等同于实际 Intel GPU 测试。

macOS 安装包采用 ad-hoc 签名，未进行 Developer ID 签名或公证；Windows 安装包没有商业代码签名。附件包含三种安装包、对应提交的源码 ZIP 和 `SHA256SUMS`。集成发行包含 AGPL / GPL 等组件，许可与对应源码见 `DISTRIBUTION_LICENSE.md` 和 `THIRD_PARTY_NOTICES.md`。
