# Open Office 0.11.0 · PDF、自动保存与浏览器工作区

PDF 工作区改用本地 Rust/WASM 编辑器，与文字、表格、演示共享文件操作、主题和多文档标签。新增自动保存和 Server，可通过本机或局域网浏览器继续编辑。

## 新增与改进

- PDF 支持阅读、文字编辑、批注、表单、搜索及页面整理。中文文字可编辑、导出并重新打开；文件操作由顶部统一管理。原有 PDF 子进程后台已移除。
- “自动保存”开关位于保存按钮旁，每 30 秒保存已选择本机位置的当前文档。新建、首次导入或需要转换格式的文件先由用户手动保存。
- 点击 **Server → 启动 Server** 获取本机或局域网访问链接，浏览器直接访问，无需账户或配对码。文字、表格、演示和 PDF 在编辑停顿后自动双向同步。
- 未确认的单元格、表单、文本框及输入法草稿会等待用户确认，后台同步和保存保留当前编辑状态。保存期间继续输入时，旧保存回执不会清除新修改的未保存标记。
- 两端同时修改同一文档时保留冲突副本；共享快照在客户端持久化。停止服务会撤销旧链接，重新启动后恢复已同步快照。
- 修复界面绘制较慢时，表格双击单元格无法进入编辑的问题；保留已有编辑草稿，并继续区分单元格、表头和图表等操作区域。
- 代码标识与运行日志统一使用 Open Office 命名，原始版权、许可证和真实依赖来源保留在法律资料中。延续 macOS 26 编辑稳定性修复。

## 使用边界

桌面应用须保持运行。浏览器保存会下载文件副本；同步到客户端工作区不等于已经覆盖本机原文件，写入原文件仍由客户端保存操作控制。

当前按整份文档快照同步，约每 1.5 秒检查更新，输入停顿至少 1.2 秒后发送；较大文档更慢。接收更新可能重置光标和撤销历史，同时修改不会自动合并文字。未同步内容仍在当前会话中，关闭前请保存或下载。

链接使用 HTTP，持有链接即可访问共享工作区，适用于可信局域网。同一端每种格式最多同时打开 7 份文档；单个共享文档上限 40 MiB，工作区上限 64 份、总计 64 MiB。详见[浏览器工作区说明](../browser-workspace.md)及[PDF 功能边界](../pdf-capabilities.md)。

## 验证与安装

发布流程要求 Windows x64、macOS ARM64 和 Intel 应用运行验证，以及 macOS 26 上实际系统键鼠编辑检查通过。Intel 安装包在 ARM Mac 上通过 Rosetta 验证，不等同于物理 Intel GPU 测试；实际系统版本以本次构建记录为准。新增 Server 生命周期、原生文件自动保存及读回也属于发布门禁。

应用仍为 Alpha，未配置商业代码签名或 macOS 开发者公证。复杂版式、公式与格式往返可能存在差异，请保留原件并核对导出结果。安装包同时提供对应源码与 SHA256 校验文件。
