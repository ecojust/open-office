# PPT 排版与正文编辑补全

2026-10-14。本轮检查了三处影响实际编辑的缺口：段距与行距只能读取、文本框布局缺少编辑入口、修改一个字会按首个文字片段重建整段。前两项已形成完整的界面、操作模型、导出和回读流程，后续迭代也补上了普通正文的差异编辑。输入框仍是纯文本输入，不是完整的画布富文本编辑器。

## 使用方式

选中普通文本框，在右侧点击“段落与文本框”。弹窗按原文的真实段落列出内容，可单独勾选、多选或全选。手动换行以 ↵ 显示，仍属于同一段落；空段落也可以设置。较长正文每组显示 100 段，支持翻组选择。

- 对选中段落设置左对齐、居中、右对齐、两端对齐。
- 行距、段前和段后间距可设百分比或固定磅值。0 是有效数值；固定行距很小时允许文字重叠，未擅自抬高到字号大小。
- 首尾段距选项控制整个文本框是否应用首段前、末段后的距离。
- 展开“文本框”设置垂直对齐、自动换行和四边内边距，内边距单位为毫米。

控件默认“保留原样”，仅应用明确设置的字段。段落与文本框设置一起提交时是一个撤销步骤。未完成输入会阻止保存，取消不改变文稿。没有增加常驻工具栏行数。

普通文字正文支持在一次输入中修改多个位置。提交时按 Unicode 文字差异修改原有片段，保留匹配文字的字体、颜色、上下标及原有段距；既有手动换行不会转换成新的段落。替换文字使用被替换起点的样式；纯插入优先使用同一行左邻片段，行首使用右邻片段，空行使用段落默认格式。按 Ctrl/Cmd+Enter 确认，Esc 取消；无法安全应用时保留输入并阻止保存。

简单的统一样式正文仍可增加、删除段落。混合格式、手动换行或各段有独立排版的正文，目前只支持在既有行内修改；涉及字段、链接、动画绑定、扩展或符号字体的复杂正文，会在进入编辑前给出限制。原本没有正文的普通矩形、椭圆也可以首次添加文字，随后继续修改。

文字差异不能恢复原生富文本编辑器的光标归属。例如两段不同样式的 `foo foo` 改成 `foo`，本实现确定性地保留前缀对应的格式，无法从最终字符串判断用户实际删除的是哪一个 `foo`。界面因此提示核对重复文字；需要时可用局部文字格式工具调整。表格单元格、图表标题和备注不属于这次普通正文改进的范围。

## 持久化与兼容策略

`format-paragraphs` 使用真实 `a:p` 索引，不按纯文本里的换行字符推断段落。动作校验正文与文稿版本，只修改所选 `a:pPr` 的明确属性；文字片段、上下标、段末属性、未选段落和其他部件均保留。它复用第六轮的物化 XML 存储和重基线策略，支持“全框格式 → 段落格式 → 局部文字格式 → 再次全框格式”的操作顺序，没有长期保存容易漂移的字符偏移。

`set-text-layout` 只更新明确设置的文本框属性。显式 `false`、零内边距以及未改边距均正确保留。包含链接等内容的段落格式沿用保守拒绝，但仍可安全修改文本框布局，保留原关系，不获取外部链接内容。

另外修复了新生成文字的默认属性：段落默认格式和段末格式现在包含与正文一致的字体、字号和颜色。此前空段或后续输入在重新打开后可能退回默认字体/字号。该改动只涉及新生成文字（包括生成的图表标题），不会因此重建导入文稿的原始正文。

正文改动在模型动作中同时提交物化 XML 和显示数据，撤销、复制、后续格式编辑及导出均使用同一基线，不延迟到导出时才补格式。差异匹配具有长度、计算量和节点数量预算，超限会拒绝整个动作，不退回有损的整段替换。原始包字节不修改；未知但可安全保留的普通 run 属性仍保留在原 `a:rPr` 上。

实现参考了固定版本公开源码的定向 REA 行为分析，没有复制其代码。补充证据 `ev_4c228dce2d584e8d6311d5a9adc929ad1f195ff4d47970ceae845618a265ae1b` 覆盖独立的段落间距、对齐、垂直对齐及逐项内边距入口；该轮跨模块摘录共 14 个函数、1276 个 AST 节点、零解析失败。规范数值与参考编辑器排版差异仍按既有排版说明保留。

正文插删另外参考证据 `ev_b7eb93f59f8bae3d72a8e53eab241314aef7fd9fcdb23d916dbc0ec7228fa0e4`：16 个函数、4 个摘录文件、8957 个 AST 节点、零解析失败。参考编辑器按活动 run 和选区执行插删，并区分手动换行与新段落；本应用的左邻插入和最终字符串差异策略是独立产品定义，不宣称与其原生光标行为完全一致。
