# 日历便笺

日历便笺把事项放在月历上，适合记录工作安排、请假和日常备忘。从工作台选择「日历便笺」新建日历本，使用顶部文件操作保存；每个日历本独立保存所有月份的事项和可复用的历史事项。

## 日期与事项

月历从星期一开始，可以切换月份或回到今天。日期格显示农历、节气和可用的中国大陆法定假日标记。

工具栏「设置」集中管理「每天工作时长（小时）」「显示范围」和「工时显示」，也可修改日历本名称。点击「确定」一次应用修改并可撤销，点击「取消」不改变原设置。这些设置作用于当前日历本的所有日期，随文件保存，不影响其他日历本。

「显示范围」中的 Week 显示周一至周日，Work 只显示周一至周五；两者都保留月历的 6 行结构。Work 按星期隐藏周末，周末调休上班日也会隐藏，周一至周五的法定假日仍显示。

切换 Week／Work 不删除或移动任何事项，不改变工时分配和整月统计。周末事项在 Work 中暂时隐藏，切回 Week 即可查看；月度统计仍包含它们。

- 单击日期只选中该日，不弹出黄历。
- 点击「日期详情」，或在日期上右键选择「日期详情」，查看该日农历与黄历。
- 在日期上右键选择「自定义」「年假」或「病假」添加事项；双击日期空白处也可新建。
- 双击已有事项可编辑标题、日期、颜色、内容和「需要上班／不需要上班」属性。

拖动事项到另一天会移动日期。按住 Ctrl（macOS 使用 ⌘）拖动会创建副本，副本保留原事项的正文，原事项不变。「搜索当月事项」可查找名称和正文，未匹配的工作段会淡化，工时总量和分配保持不变。点击日期格中的「调整」可查看该日完整事项清单并选择编辑；非工作事项较多时也可通过「另有 N 项非工作事项」打开清单。删除事项、清除当月需要确认，确认后的修改可以撤销；清除当月包含 Work 隐藏的周末事项，不影响其他月份。

## 复用历史事项

在「自定义」或编辑弹窗的「历史事项」中，使用「搜索以前用过的事项」找到已使用过的名称。选择后带入标题、颜色和是否需要上班；正文保留当前输入，新建时由你填写。

历史事项跨月份可用，跟随当前日历本保存，不与其他日历本混用。仅在确认添加或修改事项后更新历史；取消弹窗不会增加历史记录。同名事项保留最近确认的颜色和属性，最多保留 100 个名称。删除原事项或清除某个月不会清除可复用历史，添加或修改事项及对应历史更新作为同一次操作撤销。

## 同日工时分配

同一天标记为「需要上班」的事项共同组成一个胶囊，各段按分配比例伸缩。默认每天工作 7 小时：第一条工作事项占 100%，添加或拖入第二条后各占 50%；继续增加时重新平均分配。当日有工作事项时，所有工作段合计为 100%，对应完整一天的设定工时。

在工具栏「设置」中选择「百分比」或「工时」。百分比显示时，拖动两段之间的边界按全日 10% 的刻度吸附；工时显示时，按 0.5 小时吸附。也可点击「调整」在较大的胶囊中操作，选中分隔线后使用方向键调整，Home／End 移到相邻两段的起点／终点。事项较多时胶囊可横向滚动。释放鼠标提交一次可撤销的修改，Esc 取消正在进行的拖动。

调整只改变边界相邻的两项分配，同一天总量不变；其他事项可能保留平均分配时产生的非整刻度余量。某项可以调整到 0%，仍保留编辑入口，不会因此删除事项。「设置」中的「每天工作时长（小时）」范围为 0.5～24、步长 0.5；已经调整的比例会保留，小时数按新的日工时重新计算。

添加、删除、跨日移动、复制工作事项，或更改是否需要上班，会重新均分受影响日期的工作事项；只改名称、正文或颜色保留手动分配。年假、病假及其他「不需要上班」的事项单独展示，不占工作胶囊的比例或小时数。工时调整支持撤销重做，并随日历本保存。

## 当月工作统计

统计只计算当月标记为「需要上班」的事项，按各事项实际分配比例折算天数和小时，再按名称汇总。一个有工作事项的日期合计为 1 天；月度百分比以这些日期的总天数为分母。Work 隐藏的周末工作事项仍按原分配计入统计，切换视图不会缩小统计范围。

顶部「全月工作」的数量单位跟随设置：选择「工时」时显示小时，选择「百分比」时显示折合天数；每项的整月占比仍显示在旁边。提示文字和打印中的月度汇总使用相同单位，不再同时堆放天数和小时数。切换显示单位不修改事项或分配比例。

例如，某天将「会议」调整为 30%、「开发」调整为 70%，在每天 7 小时设置下分别为 0.3 天／2.1 小时、0.7 天／4.9 小时；另一天只有「开发」，计 1 天／7 小时。两天合计 14 小时，开发共 1.7 天／11.9 小时，占 85%；会议为 0.3 天／2.1 小时，占 15%。「不需要上班」的事项不参与统计；这里的百分比不是整月法定工作日容量或计划排期中的人员工时。

## 保存、打印与全屏

日历本以本地 `.oocalendar` 文件保存，包含名称、所有月份的事项、工时分配、每天工时、Week／Work、显示单位和历史事项。保存、另存为、自动保存、撤销重做、多标签和关闭前未保存提示使用工作台的统一操作。第一次保存时选择文件位置；自动保存只在具有可写位置、没有未确认表单等条件满足时进行。

「打印」按当前 Week／Work 显示 7 列／5 列月历，下方的「当前视图事项清单」列出该月可见日期的事项；Work 的打印清单只含周一至周五。打印中的全月工时统计仍包含隐藏的周末事项，完整日历存档也始终保留它们。「全屏编辑」隐藏工作台全局区域，保留日历操作和退出入口。切换月份、主题或全屏不清空内容。

可通过工作台打开 `.oocalendar`，或导入同样具有 `format: "open-office-calendar"`、`version: 1` 的完整 JSON；JSON 导入后另存为 `.oocalendar`。这不是旧 CalendarNote SQLite 数据库或任意 JSON 的迁移入口。

已有版本 1 日历本仍可打开。缺少新设置的文件使用每天 7 小时、百分比显示和 Week，未记录比例的旧事项按同日工作事项平均分配；保存后会保留这些设置。格式中 `workdayHours` 记录每天工时，`allocationDisplay` 为 `percent`／`hours`，`weekMode` 为 `week`／`work`；工作事项的 `weight` 记录 0～1 的比例，同日合计为 1。

格式限制为最多 10,000 条事项、100 条历史事项及 8 MiB 文件；标题最多 200 个字符，正文最多 20,000 个字符。导入时校验格式版本、真实日期、颜色和唯一 ID；不支持的格式不会覆盖当前日历本。

农历和黄历通过本地 `lunar-typescript` 计算。法定假日复用年度假日数据获取与缓存机制，联网请求年份数据，不上传事项名称或内容；离线时使用已有缓存，尚未发布的年份不视为已有官方安排。黄历内容为传统历法信息。

## MCP

日历便笺接入工作台已有的 MCP 服务与当前文档授权，不新增独立服务。开启方式见 [MCP 使用说明](mcp.md)。

| 工具 | 功能 |
| --- | --- |
| `calendar_read` | 按月份、起止日期、名称／正文、事项属性查询，分页返回实际份额和小时数；可带跨月历史和整月统计 |
| `calendar_edit` | 批量改名、设置每天工时、Week／Work 与显示单位，增删改事项、移动、复制、清除指定月份或分配当日工时；一批最多 100 项，作为一次可撤销操作 |
| `calendar_set_view` | 切换月份、选中日期／事项、搜索，不修改已保存的日历内容 |
| `calendar_export` | 以 JSON 返回完整日历本及历史事项；较大日历本通过界面保存 |

`calendar_read` 的起止日期含端点，与月份条件取交集；每页默认 200 条，最多 500 条。整月统计按指定月份的全部工作事项计算，不受搜索条件或分页影响。`calendar_export` 的 MCP 返回上限为 7 MiB。文档检查和撤销重做沿用通用工具，保存使用现有文件操作；MCP 的事项复制保留正文，历史事项复用不带入正文。
