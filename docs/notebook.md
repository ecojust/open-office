# 本地笔记本

笔记本工作区使用 `.oonote` 文件保存分区、页面及其内容。新建、打开、保存、另存为、打印、主题和文档标签由顶部工作台统一管理。0.13.0 增加子页面、自由布局和搜索高亮，安装包构建与验收状态以对应提交的发布流程为准。

## 功能

- 通过分区和页面整理笔记，支持新建、重命名和删除。在分区的页面列表中右键页面，选择“添加子页面”；键盘可用 Shift+F10 打开菜单。页面支持最多 8 层层级。删除父页面时会列明同时删除的子页面数量，并弹窗确认。
- 正文支持标题、粗体、斜体、下划线、删除线、项目列表、编号列表和待办勾选。
- 页面由独立内容区域组成。双击画布空白处或点击“文本区域”添加区域；拖动区域顶部移动位置，拖动右下角调整宽度。文字仅在该区域的宽度内换行，不会推动其他区域或按纸张分页。
- 拖动区域时，默认启用“智能对齐”和“网格吸附”：接近其他区域的边缘或中心时显示对齐参考线，其余位置按 10 像素网格吸附。可在笔记工具栏分别关闭；按住 Alt / Option 可临时自由移动。网格仅在拖动移动区域期间显示，松手或取消后隐藏；普通选中和调整大小时不显示网格。参考线仅在拖动对齐期间显示；方向键微调保持自由步幅。两个开关在当前打开的笔记中切换页面时保留，不写入笔记文件，也不会产生未保存修改。
- 插入 PNG/JPEG 图片，每张图片单独成区，拖动右下角等比缩放。位置与尺寸随文件保存。移动或缩放手柄获得焦点后，可用方向键微调，Shift+方向键加大步幅。
- 在文字区、图片区或点击画布空白后，可用 Ctrl / ⌘ V 粘贴 PNG/JPEG 图片和截图。macOS 从系统文件夹复制图片文件时，桌面端读取系统剪贴板中的文件引用；不会把复制的普通路径文字当作文件读取。支持一次多图粘贴，每张不超过 4 MiB、一次最多 16 张且总大小不超过 16 MiB，插入结果仍须符合笔记文件总大小限制。
- 搜索整个笔记本，点击结果后在右侧突出显示标题与正文中的匹配词；切换结果和继续编辑时仍保留高亮，清空关键词后消失。高亮不写入文件。
- 支持撤销和重做；一次拖动或缩放对应一步撤销。删除页面、分区、图片或文字区域均需弹窗确认。
- 打印当前页面。笔记本没有直接导出 PDF 命令；可通过系统打印对话框提供的存为 PDF 功能输出当前页。

桌面版打开已有 `.oonote` 后，“保存”写回原文件，“另存为”选择新的位置。新建笔记本需先手动保存；启用自动保存后，每 10 秒保存已选择本机位置的当前文档。尚未确认的输入不会被后台保存强行提交；旧保存回执不能清除较晚编辑的未保存状态。

## 文件与实现

笔记本使用本地 TypeScript 结构化模型，由 `src/notes/`、`src/components/NotebookEditor.vue` 和 `src/components/NotebookCanvas.vue` 实现。文件是 UTF-8 JSON，根标识为 `format: "open-office-notebook"`、`version: 2`，包含笔记本、分区、父子页面以及带坐标、尺寸的内容区域；图片以 PNG/JPEG 数据保存。不将任意 HTML 写入笔记文件，打开时校验格式、标识、内容与大小。

旧版 v1 文件打开时会转换为区域模型，保留文字、格式、待办与图片；只有保存时才写回 v2 文件。较旧的安装版本不能打开 v2 文件，需要回退使用时应先保留原文件。画布位置上限为 20,000 × 20,000 像素，内容区域可由用户自由移动，允许重叠。

当前文件上限为 16 MiB，单张图片上限为 4 MiB。它不是第五套 Rust/WASM 引擎，也不读取其他笔记软件的专有文件格式。暂不提供云同步、局域网共享、手写识别或附件管理。

## 验证范围

模型与会话回归入口为 `tests/notebook.test.mjs`，全局文件和标签生命周期由 App 回归覆盖。`npm run test:browser:notes` 检查真实界面的编辑、删除确认、主题、窄屏、下载重开和批量关闭；同时覆盖子页面层级、独立区域移动、图片缩放、持续搜索高亮及 v1 迁移，验证下载重开后的内容与布局一致。

`tests/notebook-snapping.test.mjs` 验证对齐与网格几何、缩放后的捕获距离、稳定吸附及画布边界。`node tests/browser/notebook-alignment.cjs` 用真实指针检查区域对齐、网格吸附、Alt / Option 自由移动、取消拖动和选择框显示。

`node tests/browser/notebook-clipboard.cjs` 检查画布粘贴、图片数据、文字兼容及键盘补偿去重；其中系统剪贴板桥使用测试替身，不能替代 macOS 文件夹复制图片后的真机粘贴验收。

上述浏览器检查不覆盖系统输入法、打印对话框、原生文件对话框和各平台安装包，这些仍需分别验收；四套 Rust 编辑器已有报告不能直接作为笔记本通过的证据。最新构建流程见[开发文档](development.md)。
