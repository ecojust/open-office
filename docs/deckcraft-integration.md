# 演示文稿 Rust 引擎集成

当前演示工作区使用 [DeckCraft](https://github.com/storytold/deckcraft) 的 Rust 模型、PPTX 解析与写入、向量 PDF 导出及 egui 编辑画布，固定上游提交为 `9859da39255c0262cd592bb57101d7f2fa961f72`。所有代码从本仓库构建为本地 WASM，随安装包分发。它是上游开源引擎的本地适配，未声称由 Open Office 从零原创。

## 文件与交互

- 支持新建演示文稿，导入 PPTX、POTX、PPSX，保存 PPTX 和导出 PDF。
- 顶部全局工具栏处理新建、打开、保存、另存为、导出和打印；编辑区保留幻灯片及文档操作。全局主题同步画布，操作栏使用 Open Office 自绘 SVG 图标。
- 每个标签使用独立文稿会话、选区和撤销历史。导入先在独立会话解析，失败不会覆盖当前文稿。
- 导入的文稿首次保存生成副本，POTX/PPSX 不覆盖原模板或放映文件。保存收据只确认对应导出快照，保存期间新增的编辑继续显示为未保存。
- 文件、标签和主题切换前处理待提交文字。未完成的输入法组合会阻止保存；图片和媒体选择通过带文档、版本和选区身份的回执应用，避免插入错误标签。

中文界面与文稿使用随包的 LXGW WenKai 字体回退；拉丁文字、符号和部分单色 emoji 使用已记录来源的字体。显示和 PDF 输出都从同一 Rust 文稿模型产生，字体覆盖及排版仍受上游实现限制。

## 旧内核移除

当前源码已移除 LibreOffice/ZetaOffice/Qt WASM 兼容内核、UNO 桥接、旧运行时下载与补丁、早期 TypeScript Word/Sheet/PPT 模型及编辑器、旧 `word-engine`/`word-package` Rust crate 和原生 IPC。字体资源独立迁移至 `assets/fonts/`，当前 WordCraft、GridCraft 和 PDF 工作区保留。

旧 DOC、RTF、ODT、XLS、ODS、PPT、ODP 已从新建、打开和保存选项移除。旧最近文件条目仍能读取，但打开不支持的文件会明确失败，需先转换成支持格式。历史兼容语料与专项报告保留作追溯，不是当前内核的通过证明。

## 验证与边界

`tests/deckcraft-client.test.mjs` 检查会话隔离、失败导入、延迟保存回执、输入法组合、主题切换和异步媒体选择。`tests/browser/deckcraft-native-helper.cjs` 使用实际 Vue 工作台、Rust WASM 画布和 DOM 输入，生成 PPTX/PDF 后重开；独立 Python 检查器读取实际 ZIP/XML、PDF 页数及中文文本。原生安装包流程还要求安装目录与 WebView 加载资源的摘要一致。

2026-10-15 的本地验证已通过生产构建、258 项 Node 测试、83 项 PDF 后端测试、21 项原生文件存储与验收报告测试、5 项 PPT Rust 宿主回归测试，以及 Word、Sheet、PPT 的真实 WASM 浏览器验收和全局工具栏／主题验收。PPT 导出的 PPTX 和 PDF 通过独立解析，浏览器未请求旧内核资源。构建也检查旧源码、原生依赖及分发资源是否残留。

发布前额外通过当前 WASM 宿主、界面、引擎及字体包的严格 Clippy 检查。独立上游的完整 `cargo xtask ci` 已尝试，但在无平台过滤的依赖查询下载 Windows 交叉目标依赖时被网络代理以 403 拒绝；后续全工作区检查未完成。限定本机平台后的 PDF 依赖边界检查通过，不将其等同于上游完整 CI。

浏览器验证不代表 Windows WebView2 或 macOS WKWebView 已通过。上述原生文件测试未覆盖 Tauri 对话框与 IPC 包装层。发布流程会分别验证三个平台，并在全部通过后公开安装包；本次集成包含于 0.10.0，安装包发布状态以对应发行页为准。

当前 WASM 宿主可插入并保存音视频，但上游 Web 播放路径没有声音输出，不能作为完整音视频放映功能使用。

外部主题导入、文件比较、从文件复用幻灯片、SmartArt 图片选择、自定义切换声音、相册添加图片，以及形状／背景图片填充的文件选择暂未支持。相应入口在编辑区禁用并说明原因；内置选项和已有内容仍可编辑，常规图片、音频、视频插入不受影响。

DeckCraft 上游仍在发展；复杂 SmartArt、动画、媒体、母版、特殊字体和精细布局可能不能完整保留，菜单存在不等于对应格式已通过验收。请保留重要原件并核对实际导出。
