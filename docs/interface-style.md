# 界面字体与图标

主页、全局工具栏、文字、表格、演示、PDF 和笔记本共享以下界面规范。

| 项目 | 规范 |
| --- | --- |
| 西文字体 | 本地 Inter Regular / SemiBold，400 / 600 |
| 中文字体 | 本地文泉驿微米黑，真实 Regular 字重，不合成粗体 |
| 常用文字 | 正文和控件 13px，辅助说明 11px，弹窗标题 18px |
| 图标画法 | 原创 SVG，24 × 24 网格，1.65 圆端点与圆转角描边 |
| 图标尺寸 | 常用工具 18px，大按钮 28px；箭头、标签关闭和状态图标按辅助层级缩小 |
| 图标颜色 | 前景跟随深浅主题，强调色保留各工作区辨识，禁用状态统一淡化 |

Rust 界面从 `src/shared/office-ui-fonts.rs` 安装同一组字体；网页 CSS
直接引用同一份字体文件。字体在构建时打包，不依赖系统安装或在线字体服务。
出处、许可及提取方式见 [`assets/fonts/ui`](../assets/fonts/ui/README.md)。

共享图标的源与校验规则见[图标说明](../src/icons/README.md)。笔记本工具栏
通过 `shell-aliases.json` 直接复用编辑器 SVG，避免使用会随字体变化的字符图标。

这些规范只作用于应用界面。文档内的字体选择、字号、单元格样式、演示对象、
PDF 页面内容及笔记正文样式仍由文档设置控制。

修改后执行 `npm run build`、`npm test`，再运行
`npm run test:browser:ui-style`，依次检查六种界面的浅色、深色和较窄窗口截图。
浏览器验证不替代桌面原生 WebView 验收。
